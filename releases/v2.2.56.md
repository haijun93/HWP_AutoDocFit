# v2.2.56

## 바뀐 점
- **업무자료함 내보내기 안정성 강화 (klib)**: 상자 내보내기 시 재귀 복사 무한 루프 위험을 차단하고, 관리 경로 및 Windows 경로 별칭(심볼릭 링크·정션)에 대한 겹침 검증 로직을 보강했습니다.
- **보안 취약점 개선**: klib 의존성 `quick-xml`을 0.41.0으로 상향하여 XML 서비스 거부 취약점(RUSTSEC-2026-0194, RUSTSEC-2026-0195)을 해결했습니다.
- **위계검색 명칭 정리**: 타임라인 내 관련 문서 탐색 기능의 명칭을 기존 「연관검색」에서 「위계검색」으로 직관화했습니다.
- **작업 방식 화면 정돈**: 작업 방식 선택 화면에서 사용 빈도가 낮은 '페이지 맞춤' 카드를 정리하여 화면 구성을 단순화했습니다(백엔드 기능 및 옵션은 유지).
