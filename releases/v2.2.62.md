# v2.2.62

## 바뀐 점
- **타임머신 검색의 위계 판정을 바로잡았습니다**: □·ㅇ·- 항목기호 문장이 「장·절·주제」로 잘못 올라가던 문제를 고쳐, 항목기호 단계 그대로 판정합니다. 검색 순위와 결과의 상위 경로가 더 정확해집니다.
- Markdown 문서에서 제목 아래의 「1. 2. 3.」 번호 목록은 본문으로, 표 줄(「| … |」)은 표 칸으로 판정합니다.
- **범정부 라벨 문서를 인식합니다**: 「네모:」「원:」「바:」「주석:」으로 쓴 글을 □·ㅇ·-·부연설명 위계로 읽고, 상위 경로에는 「□ 추진 배경」처럼 기호로 보여 줍니다. 「개요:」는 본문으로 봅니다.
- 업데이트 뒤 첫 실행 때 본문 색인이 배경에서 자동으로 다시 만들어집니다.

## 재연 시험
- Python 전체 시험(CI) 통과, 합성 문서 180개 검색 품질 측정에서 재현율·순위·경로 정확도 변화 없음.
- 실제 업무 문서와 앱 화면에서의 확인은 하지 않았습니다.
