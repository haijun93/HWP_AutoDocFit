# v2.2.79

## 바뀐 점
- **퀵몽땅검색 화면 정리**: 기간·형식 칩 줄과 '검색 결과 n건' 요약 줄이 겹쳐 글자가 덮이던 문제를 고쳤습니다. 모든 줄의 위치를 한 곳에서 계산하도록 바꿔 그리기와 마우스 클릭 판정이 어긋나지 않습니다. 옵션 줄의 '결과 내'가 잘리던 것, 오른쪽 위에 보이던 세로 띠, 영어가 섞여 있던 안내 문구("Up/down select | Enter load")도 정리했습니다. 안내 문구는 "↑↓ 선택 · Enter 열기 · Ctrl+D 즐겨찾기"입니다.
- **홈 버튼 제거**: v2.2.76·v2.2.77에서 넣었던 화면 왼쪽 위 홈 버튼과 퀵몽땅검색·퀵몽땅클립보드·퀵가상폴더 창의 홈 버튼을 모두 뺐습니다.
- **하단 Dock(시험판) 보강**: 메뉴 아이콘을 직접 그리고, 마우스를 올리면 이름이 보이며, 방향키·Enter로 고를 수 있습니다. 고대비 모드에서는 시스템 색을 씁니다.
- **PDF 편집**: 분할 범위가 문서 쪽 수를 넘으면 오류로 알리고, 결과 파일 경로가 원본과 같으면 작업을 거부합니다(원본 덮어쓰기 방지).

## 알려진 문제
- 하단 Dock은 시험판입니다. 모든 메뉴 창이 Dock에서 바로 열리지는 않습니다.
- 퀵몽땅검색 화면 수정은 시험으로 검증했지만 실제 화면(배율 100~200%)에서의 확인은 설치본에서 해야 합니다.

## 재연 시험
- 릴리스 직전에 실제 설치본에서 시험하고 채울 항목입니다(초안 단계에서는 미실행).
