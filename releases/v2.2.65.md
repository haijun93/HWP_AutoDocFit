# v2.2.65

## 바뀐 점
- **앱 안 검색 새 엔진 교체와 자동 대체**: 앱 안의 본문검색과 위계검색 엔진을 독자 검색 엔진(kfind)으로 즉시 교체했습니다(기본값 `kfind`). 새 엔진 서비스가 연결되지 않거나 오류가 생기면 예전 검색 방식(SQLite/Tantivy)으로 자동 대체(fallback)하여 검색이 멈추지 않으며, 상태 줄에 대체 사유를 안내합니다.
- **독자 검색 엔진 공개와 라이선스**: Rust로 자체 개발한 검색 엔진 코드(`kfind/`, `crates/kfind/`)를 GitHub에 공개했습니다. 검색 엔진 코드는 MIT가 아닌 PolyForm Strict 1.0.0 라이선스에 출처 표시 조건을 더해 배포됩니다(비상업적 목적 사용만 허용, 재배포·수정·2차 저작물 작성 금지, 출처 표시 필수).
- **몽땅검색 이름 변경**: 기존의 "타임머신" 기능 명칭을 "몽땅검색"으로 변경했습니다(화면 제목, 메뉴 탭, 안내 문구 등).
- **업무자료함 색인 분리·첫 실행 때 자료 옮기기**: 업무자료함 데이터를 공용 데이터베이스와 색인에서 별도 데이터베이스(`library/notebook/notebook.db`) 및 별도 색인으로 분리했습니다. 첫 실행 시 기존 자료를 안전하게 옮기는 작업(백업→복사→색인→검증→전환)을 자동으로 진행하며, 실패하더라도 기존 자료를 보존하고 다시 시도할 수 있습니다. 쉬는 시간에 바뀐 출처만 자동으로 다시 색인합니다.
- **다크 모드**: 라이트, 다크, 고대비 테마를 지원합니다. 보조 프로그램(kagent, kvf) 및 앱 창에 다크 제목줄과 테마 색상을 적용하고, 설정을 바꾸면 즉시 다시 그립니다.
- **화면캡처·그림 미리보기**: 몽땅클립보드에서 Windows 화면캡처 폴더를 자동으로 감시하여 기록하고, 그림 항목에 마우스를 올리거나 키보드로 선택하면 미리보기가 뜹니다(썸네일은 쉬는 시간에 미리 생성).
- **몽땅검색 단축키 앱**: 어느 화면에서나 단축키(Ctrl+Alt+Space)로 몽땅검색 창을 띄울 수 있는 빠른 검색 앱 기능은 기본 켬 설정으로 포함 예정입니다(다음 통합 카드 반영).
