# v2.2.65

## 바뀐 점
- **앱 안 검색을 독자 검색 엔진으로 교체**: 몽땅검색(본문·위계)·가상 폴더·업무자료함 검색이 기본으로 새 검색 엔진(kfind)을 씁니다. 같은 문장 안에 함께 나온 낱말을 찾고, 붙여 쓴 검색어(예: 예산집행)도 찾습니다. 검색 서비스가 연결되지 않거나 오류가 나면 예전 검색(SQLite FTS5)으로 자동으로 돌아가 검색이 멈추지 않으며, 상태 줄에 그 사실을 표시합니다. 검색 서비스(kfind.exe)는 앱이 시작할 때 사용자 권한으로 함께 뜹니다.
- **몽땅검색 단축키 앱(기본 켬)**: 어느 화면에서나 Ctrl+Alt+Space로 몽땅검색 창을 띄웁니다. 파일명·본문·위계 탭이 검색어를 공유하고, Enter·더블클릭으로 문서를 엽니다. 앱 설정에서 끌 수 있습니다.
- **독자 검색 엔진 코드 공개**: `kfind/`, `crates/kfind/`, `kfind/names/`, `ktm/`은 앱의 MIT 라이선스가 아니라 PolyForm Strict 1.0.0 + 출처 표시 조건을 따릅니다(비상업적 사용만, 재배포·수정·2차 저작물 금지, 사용·인용·언급 때 출처 표시).
- **이름 변경**: "타임머신" 기능을 "몽땅검색"으로 바꿨습니다.
- **업무자료함 색인 분리**: 업무자료함을 별도 DB·색인으로 분리했습니다. 처음 실행할 때 기존 자료를 옮기며(먼저 백업, 실패하면 원래 자료 유지), 바뀐 출처는 출처 번호를 바꾸지 않고 쉬는 시간에 다시 색인합니다.
- **다크 모드**: 라이트·다크·고대비, 시스템 설정 따라가기. 몽땅클립보드·가상 폴더 창에도 적용됩니다.
- **몽땅클립보드**: 화면캡처 폴더를 자동으로 찾아 기록하고, 그림 항목에 마우스를 올리면 미리보기가 뜹니다(썸네일은 쉬는 시간에 미리 만듦).
- README에 영어 설명을 추가했습니다.

## 알려진 문제
- 몽땅검색 단축키 창이 뜬 직후 곧바로 입력하면 첫 결과가 가끔 0.4~0.6초 늦습니다(0.25초 뒤 입력하면 약 10ms). 다음 버전에서 고칩니다.
- 관리자 권한 검색 서비스 설치 버튼은 아직 없습니다(지금은 사용자 권한으로 자동 실행).

## 재연 시험
- Rust 시험(검색 엔진·파일명 엔진·검색 서비스·단축키 앱·몽땅클립보드·가상 폴더), Python 전체 3,141개, Flutter 673개 통과(이 PC, CI).
- 실제 업무 문서·한/글 화면·설치본에서의 손 확인은 하지 않았습니다.
