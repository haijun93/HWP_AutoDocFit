# v2.2.35

## 바뀐 점
- 노트북 메모 편집기(개발자 모드)가 Rust 편집 엔진을 사용: 여러 단계 실행취소, 찾기·바꾸기, Ctrl+휠 확대·축소, 상태 표시줄(줄·열·글자 수·확대 비율·줄바꿈·인코딩)
- 자료함(개발자 모드): '+메모'로 메모를 써서 텍스트 항목으로 추가, 기존 텍스트 항목을 더블클릭하면 같은 메모 편집기로 열어 고치기
- 몽땅클립보드 관리창: 분류 탭을 빠른 목록과 같은 이름·기준으로(전체·문서·그림·파일·폴더·웹·화면캡처·키워드검색)
- 메모 편집 엔진: 열 때 UTF-8·UTF-16·CP949 자동 감지, 모두 바꾸기를 한 번에 되돌리기, 100만 글자 문서 성능 개선

## 배포 검증
- CI 통과(실행 42369308862), GitLab 보안 검사 사전 통과, Python 2504개·Flutter 458개·자료함 엔진 116개·편집 엔진 37개 시험 통과
- 배포 파일 화면 시험·이 PC 점검 통과, 자료함·노트북·사이드메뉴 모드·'항상 위' 실제 확인 통과
