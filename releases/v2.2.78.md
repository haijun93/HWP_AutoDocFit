# v2.2.78

## 바뀐 점
- **PDF 편집 화면 상호작용**: 쪽 카드를 클릭·Shift/Ctrl로 고르고, 회전(좌·우 90도)·삭제·드래그(또는 방향키)로 순서를 바꿀 수 있습니다. 변경은 되돌리기·다시하기가 되고, 저장하면 새 파일(`<원본>_편집.pdf`)로 한 번에 적용됩니다. 여러 PDF 합치기(파일 순서 변경)와 쪽 범위 분할, 진행 표시·완료 카드가 있습니다. 쪽 수와 썸네일도 표시합니다.
- **메뉴 표시 방식 선택(시험판)**: 설정에서 왼쪽 사이드바와 하단 Dock 중 고를 수 있습니다. 기본은 지금의 사이드바입니다. Dock은 작업표시줄 바로 위 가운데에 떠 있고 아이콘을 누르면 해당 기능이 열립니다. Dock을 켜지 못하면 자동으로 사이드바로 돌아옵니다. 아직 시험판이라 일부 기능 창 연결이 완성되지 않았습니다.
- **사진뷰 태그**: 사진에 태그를 붙이고 태그 칩으로 걸러 보거나 `#tag:태그명`으로 검색할 수 있습니다.
- **퀵몽땅검색**: 서비스 응답이 늦을 때 무기한 기다리지 않고 시간이 지나면 오류로 알려 줍니다(검색 5초). 기간 선택 목록과 일수 입력 한도(최대 36,500일)를 정리했습니다. 파일명·위계·본문 통합 검색의 합성 규칙을 시험으로 고정했습니다.
- **검색 엔진**: `;`로 묶은 연관 검색어의 개수 집계가 제외어 문서를 세던 오류를 고쳤습니다.

## 알려진 문제
- 하단 Dock은 시험판입니다. 모든 메뉴 창이 Dock에서 바로 열리지는 않습니다.
- 사진뷰 태그는 앱 자료에만 저장되고 검색 색인과는 아직 합쳐지지 않았습니다.

## 재연 시험
- 릴리스 직전에 실제 설치본에서 시험하고 채울 항목입니다(초안 단계에서는 미실행).
