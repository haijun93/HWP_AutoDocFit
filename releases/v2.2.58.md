# v2.2.58

## 바뀐 점
- **검색이 빨라졌습니다(타임머신 위계검색·본문검색)**: 문단 위치 대응 표를 두어 결과마다 색인 전체를 훑던 조회를 없앴습니다. 합성 색인(3,000문서 × 80문단) 기준 드문 말 위계검색 44.0초 → 0.01초, 흔한 말 본문검색 182초 → 5.9초, 2쪽 넘김 5.6초 → 0.44초입니다.
- **본문검색 오류 3건 수정**: 2글자 검색어에서 문서가 빠지던 문제, 후보 문서가 많을 때(약 3만 건 이상) 검색이 실패하던 문제, 검색 결과의 위치·발췌문이 비어 나오던 문제를 고쳤습니다.
- **자료함(가상 폴더) 검색 개선**: 순위를 위계 우선(제목·장·절에 있는 말이 먼저)으로 바꾸고, hwpx·docx 문서의 위계 수준을 색인에 넣었습니다. 같은 파일이 결과에 여러 번 나오지 않고 한 건으로 묶입니다. **업데이트 뒤 첫 실행 때 자료함 색인이 배경에서 자동으로 다시 만들어지며, 그동안 검색 결과가 일부만 나올 수 있습니다.**
- **파일 변환 TXT → PDF·HWPX 수정**: 줄 머리 들여쓰기가 사라지고 `,`·`:` 앞에 역슬래시가 남던 문제를 고쳤습니다. TXT는 줄 그대로 담깁니다. USB(exFAT·FAT32) 등 하드 링크를 못 쓰는 폴더에도 결과를 저장합니다.
- **몽땅클립보드**: 다른 프로그램이 같은 단축키를 쓰고 있어 등록에 실패하면 알림으로 알려 주고, 트레이 풍선말에 '단축키 사용 불가'를 표시합니다. 상태 파일이 깨져 앱이 K에이전트에 연결하지 못할 수 있던 문제를 고쳤습니다.
- **Rust 위계 엔진**: 같은 문서를 분석할 때마다 결과가 달라질 수 있던 문제(번호가 섞인 문서)를 고쳤고, Flutter 화면에서 엔진을 불러오지 못하던 연결을 복구했습니다.
- **편집기·자료함 엔진 응답 속도**: 요청마다 20~31ms씩 기다리던 대기를 없앴습니다(요청 왕복 최댓값 70.5ms → 0.36ms). 자료함 파일 200개 묶음 색인이 0.4초로 줄었습니다.
- **처음 체험용 예시 문서**를 「[모의데이터]문서편집_작업방식(한번에적용) 기능시연용문서.txt」로 교체했습니다.

## 알려진 문제
- 후보가 전체 문서인 흔한 말 본문검색은 아직 수 초가 걸립니다.
- 단축키 등록 실패 알림은 Windows 알림 설정에 따라 표시되지 않을 수 있습니다.
