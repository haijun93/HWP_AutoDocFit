# v2.2.63

## 바뀐 점
- **모든 검색창이 실시간으로 찾습니다**: 2글자 이상 입력하면 Enter 없이 바로 검색합니다. 1글자는 Enter를 누르면 찾습니다.
- **타임머신**: 파일명·본문검색·위계검색이 검색어를 공유하고, 메뉴를 바꾸면 같은 검색어로 바로 다시 찾습니다.
- **업무자료함**: 본문검색과 출처비교가 검색어를 공유하고, 메뉴를 바꾸면 자동으로 다시 찾습니다.
- **가상 폴더**: 검색창에 본문검색·위계검색을 추가했습니다(타임머신 조사 폴더 안의 문서 대상).
- 위계검색이 기준 문서 없이 검색어만으로도 결과를 보여 줍니다.
- 표 단위·준말·상용구·설정 검색도 같은 방식(2글자부터 실시간)으로 바꿨습니다.
