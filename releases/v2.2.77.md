# v2.2.77

## 바뀐 점
- **문서뷰·사진뷰: 폴더를 고르지 않아도 됩니다**: 두 화면이 바탕화면을 포함한 모든 고정 드라이브를 기본 범위로 씁니다. 시스템·프로그램 폴더(Windows, Program Files, AppData, 휴지통 등)와 개발 폴더는 자동으로 빼고, 설정에서 '제외할 폴더'를 추가·삭제할 수 있습니다. 순회는 백그라운드에서 진행 표시와 취소를 지원합니다. 시작 폴더가 AppData 아래여도 그 폴더 전체가 제외되지 않도록 판정 기준을 시작 폴더 기준으로 바로잡았습니다.
- **아웃라이너**: 최근 페이지를 다음 실행에도 기억하고, 여러 페이지를 가로지르는 간단 쿼리(할 일·태그·링크·속성·본문), 일일 일지 이름 규칙, `((블록 참조))` 해석, 페이지 이름을 바꿀 때 링크 일괄 갱신을 엔진에 추가했습니다.
- **업무 연보**: 월별 막대·주차×요일 열지도·주제 타임라인을 SVG로 내보내고, 인수인계·실적 보고서용 데이터(JSON)를 만듭니다. 서로 다른 연도의 같은 주 번호가 합쳐지던 오류를 고쳤습니다(v2.2.76 포함).
- **검색 색인**: 색인 파일을 쓸 때 연속 구간을 압축해 크기를 줄였습니다(결과는 같습니다).
- **내부 준비**: 하단 Dock 메뉴바의 상주 프로그램 골격과 아이콘 클릭 처리를 넣었습니다. 아직 설정에서 켤 수 없습니다.

## 알려진 문제
- 사진뷰 태그 화면은 아직 연결되지 않았습니다.
- 모든 드라이브를 처음 훑는 시간은 PC에 따라 길 수 있습니다(설치본에서 측정 전).

## 재연 시험
- 릴리스 직전에 실제 설치본에서 시험하고 채울 항목입니다(초안 단계에서는 미실행).
