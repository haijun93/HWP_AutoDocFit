# v2.2.87

## 바뀐 점
- **퀵가상폴더 화면 정리**: 좁은 영역의 안내 문구(빈 상자·오류·검색 결과 없음)가 끝에서 잘리던 것을 두 줄로 접어 끝까지 보이게 했고, 끌어 놓을 영역의 머리글을 강조색으로 칠해 활성 영역과 구별되게 했습니다. 상태줄의 마지막 작업 문구가 일찍 잘리던 것, 큰 아이콘 이름이 앞 몇 글자만 보이던 것(두 줄로 접음)도 고쳤고, 영문 꼬리표 `[file]`·`[link]`·`[folder]`를 `[파일]`·`[링크]`·`[폴더]`로 바꿨습니다.
- **앱 시작 시 404 오류 후보 제거**: 화면에 빈 아이콘을 지정해 브라우저가 존재하지 않는 `favicon.ico`를 따로 요청하는 것(실행 기록에 남던 404 오류의 유력한 후보)을 막았습니다.
- 내부: 런칭 경로 분석 문서(`docs/LAUNCH1_RESULT_2026-11-21.md`)와 웹 자원 대조 스크립트, 색인 메모리 실측 문서(`docs/KFMEM3_RESULT_2026-11-21.md`), v2.2.86 사용자 확인 체크리스트(`docs/USER_VERIFY_CHECKLIST_v2.2.86.md`)를 추가했습니다.
