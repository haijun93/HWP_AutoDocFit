# v2.2.99

## 바뀐 점
- 내부(기본 동작 불변, 앱에 연결되지 않음): **Rust 몽땅검색엔진 통합 준비**. 검색 backend 계약(`SearchBackend`)과 기존 SQLite 어댑터, 설정 키 `search_backend_mode`(`sqlite` 기본, `rust`·`shadow_compare`는 선택, 화면에는 숨김), klib(Tantivy) 연결, 배치 색인, 위계·위치 필드(schema v5), 문서 지문 변경 감지, 질의 지연 개선을 담았습니다. 합성 코퍼스(5천 문서)에서 Rust는 초기 색인이 SQLite의 약 10%, 디스크가 약 14%, 질의 지연이 8~28ms이고 결과 문서 집합이 일치했습니다. 실제 한글 문서·스캔 PDF·설치본 시험을 하지 않았으므로 기본 전환은 하지 않았습니다.
- **공용 자료함 검색의 점수·응답 구조는 v2.2.97과 같습니다.** 이전 시도(v2.2.98 후보)에서 이 부분이 달라져 klib 시험 4건이 깨졌고, 이번에 기준선 동작으로 복원했습니다(`cargo test` 전체 통과).

## 알려진 문제
- v2.2.86~v2.2.98 노트의 '알려진 문제'가 그대로 남아 있습니다.
- Rust 검색의 순위 품질은 합성 정답 기준으로만 확인했습니다. 실제 문서에서 SQLite와 순위가 얼마나 다른지는 확인하지 못했습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
