# v2.2.76

## 바뀐 점
- **아웃라이너(새 사이드메뉴, Logseq식)**: 블록 트리 메모에 들여쓰기·접기, `[[페이지]]` 링크와 역링크, 일일 일지, `#태그`·속성, TODO/DONE 표시, 검색을 넣었습니다. 저장은 마크다운 파일이며 Rust 엔진(`outliner.exe`)이 처리합니다. 키보드(Enter·Tab·Alt+방향키·Ctrl+Enter·Backspace)와 페이지 이름 변경·삭제, 링크 자동완성을 지원합니다. 설정의 '쓸 메뉴 고르기'에서 켜고 끌 수 있습니다.
- **PDF 편집 화면 새 디자인**: 도구 막대, 파일을 끌어다 놓는 영역, 파일 카드, 쪽 썸네일 격자(쪽 수 표시), 작업 패널로 다시 구성했습니다.
- **퀵몽땅검색**: 결과를 두 줄 카드로 보이게 했고, `;`로 나눈 연관 검색어를 검색칸 아래 칩으로 표시합니다. '파일명 제외'가 본문을 아직 불러오지 않은 행을 숨기지 않도록 고쳤습니다.
- **검색 엔진**: 그룹 질의를 결과 본문 없이 개수만 세는 기능(`count_groups`)을 추가했습니다.
- **업무 연보**: 주차별 주제·요일 열지도·연월 타임라인 CSV를 내보냅니다. 서로 다른 연도의 같은 주 번호가 합쳐지던 오류를 고쳤습니다.
- **사진뷰**: 사진 태그를 자료함에 저장하고 태그로 검색하는 엔진 명령을 추가했습니다(화면 연결은 아직 없습니다).
- **위계 추출**: PDF 줄 단위 추출과 번호 체계(Ⅰ./1./가.) 위계 판정을 추가했습니다.

## 알려진 문제
- 사진뷰 태그 화면과 아웃라이너의 최근 페이지 영속 저장은 아직 연결되지 않았습니다.

## 재연 시험
- 릴리스 직전에 실제 설치본에서 시험하고 채울 항목입니다(초안 단계에서는 미실행).
