# v2.2.71

## 바뀐 점
- **퀵가상폴더(Win+Shift+F) 탐색기 개편 (1~3단계)**: Windows 파일 탐색기 스타일로 창을 전면 개편했습니다. 1~4 분할 영역 레이아웃, 주소줄, 목록/큰 아이콘 보기, 영역 분할선 크기 조절, 영역 간 드래그앤드롭 이동 및 Ctrl 드래그 복제, 우클릭 컨텍스트 메뉴, 실행 취소(Ctrl+Z) 및 다시 실행(Ctrl+Y)을 지원합니다.
- **퀵몽땅검색(Ctrl+Alt+Space) 고도화**:
  - 검색 결과 CSV/TSV 내보내기(`Ctrl+E`, 최대 1,000건, UTF-8 BOM 지원으로 엑셀 한글 깨짐 방지).
  - 일치 문장 위치 배지 표시, 선택 결과 3줄 미리보기, 본문 탭 정렬 순환(`Ctrl+S`).
  - 최근 검색어 자동 저장 및 검색 결과 즐겨찾기(`Ctrl+D`).
  - 단축키 창 제목을 '퀵몽땅검색'과 '퀵가상폴더'로 통일.
- **붙임사진 편집 도형 크기 복사 버그 수정**: 크기를 조정한 도형을 복사(`Ctrl+C`)하여 붙여넣기(`Ctrl+V`) 또는 복제(`Ctrl+D`)할 때 기본 크기로 초기화되던 문제를 수정하여, 조정한 치수 그대로 복사·붙여넣기 및 저장이 유지되도록 했습니다.
- **파일변환 'PDF 압축' 목표 크기 지정**: 사용자가 원하는 목표 파일 크기(기본값 10MB)를 지정하면, 목표치 이하가 될 때까지 품질을 단계적으로 낮추어 최적의 용량으로 압축합니다.
- **파일변환 '이미지 PDF' 변환 추가**: 결과 포맷에 '이미지 PDF'(`pdfi`)를 새로 추가했습니다. 쪽마다 고해상도 그림으로 렌더링하여 글자 선택·복사·검색이 불가능한 배포용 PDF를 원본 규격 그대로 생성합니다.
- **서식 통일 카드 옵션**: 작업 방식의 서식 통일 카드에서 '전체 서식 맞추기'를 켤 때 지원하지 않는 카드 옵션 오류가 발생하던 문제를 해결했습니다.
