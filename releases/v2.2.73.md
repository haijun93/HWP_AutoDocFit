# v2.2.73

## 바뀐 점
- **PDF 편집(새 기능)**: 페이지 삭제·순서 변경·회전·분할·합치기를 Rust 엔진(`pdf-edit`)으로 합니다. 앱에 'PDF 편집' 탭이 생겼고, 결과는 항상 새 파일로 저장하며 원본은 건드리지 않습니다. 암호·권한 PDF와 손상된 PDF는 실행 전에 분류해 안내합니다. 기존 PDF 압축·이미지 PDF·문서 변환은 그대로입니다.
- **검색 색인 개선**: 본문 색인의 2글자 조각 표가 경로 문자열 대신 문서 번호를 저장해 DB 크기가 크게 줄고(합성 3,000문서 33.5MB → 10.8MB), 색인 시간이 줄었습니다(검색 엔진 내부 색인 시간 합성 측정 −60%). 옛 색인은 지우지 않고, 아직 옮기지 못한 문서는 기존 방식으로 검색한 뒤 다시 색인할 때 옮겨집니다. 검색 결과는 같습니다.

## 알려진 문제
- 업데이트 직후에는 문서를 다시 색인하는 동안 일부 검색이 기존 속도로 돕니다.

## 재연 시험
- 전체 시험 통과(이 PC, 건너뜀 14건 제외), Rust(kfind·pdf_edit_core) 시험 통과.
- PDF 편집은 합성 PDF로 삭제·회전·순서 변경·합치기·분할을 실제 엔진에 돌려 확인. 설치본의 화면 확인은 게시 전 별도 확인.
