# v2.2.74

## 바뀐 점
- **퀵몽땅검색 '전체' 탭**: 파일명·위계·본문 결과를 한 목록으로 합쳐 보여 주고, 같은 문서는 한 행으로 합치며 근거만 배지로 표시합니다.
- **퀵몽땅검색 와일드카드 검색**: 낱말 안에 `*`(0개 이상 글자)와 `?`(한 글자)를 쓸 수 있습니다. 정규식 검색은 안전하게 처리할 방법이 없어 이번에는 넣지 않았습니다.
- **본문 색인 DB 크기 감소**: 2글자 조각 표를 경로 문자열 대신 문서 번호로 저장합니다(합성 3,000문서 기준 DB −63%, 색인 시간 −36%). 옛 DB는 지우지 않고 앱을 쓰면서 새 구조로 옮겨지며, 옮겨지기 전 문서는 기존 방식으로 검색합니다. 검색 결과는 같습니다.
- **업무 연보 내보내기(개발자용 명령)**: 분석 결과를 인수인계 보고서(마크다운)와 엑셀용 CSV로 내보내는 `annual report` 명령을 넣었습니다(화면 연결은 다음 버전).
- **개발 기반**: 시험이 사용자 데이터 폴더를 건드리지 못하게 보호 장치를 넣었고, 디지털 PDF 텍스트 추출기와 kordoc 비교 도구를 추가했습니다(변환 경로에는 아직 연결하지 않았습니다).

## 알려진 문제
- 업데이트 직후 몇 분 동안은 색인 DB를 새 구조로 옮기는 중이라 본문 검색이 기존 속도로 돌 수 있습니다.

## 재연 시험
- 전체 시험 3,267건 통과(이 PC, 건너뜀 15건 제외), Rust(kfind·klib·ktm) 시험 통과.
- 색인 DB 변환은 이 PC의 실제 DB 사본에서 확인했고, 설치본에서의 변환은 게시 전 확인합니다.
