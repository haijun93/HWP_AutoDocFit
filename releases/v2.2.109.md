# v2.2.109

## 바뀐 점 (한번에 적용의 저장·실패 상태)
- 저장 직후 결과 파일을 목록에 올립니다. 저장 뒤 중단하거나 검수에 실패해도 결과 파일이 목록에 남고 상태가 따로 표시됩니다.
- 저장 뒤 검수를 마치지 못한 문서(재열기 실패 등)는 '검수 실패'로 처리합니다. **전에는 성공으로 셌지만 이제 실패 수에 들어갑니다.**
- 한 문서가 실패해도 다음 문서를 계속 처리하며, 실패가 있으면 '모든 작업 완료'로 표시하지 않습니다.
- 문서 사이 한/글 재시작에 실패하면 남은 문서를 미처리로 알립니다. 재시작하지 않는 설정에서는 실패한 문서를 저장 없이 닫습니다.
- 이어하기는 완료 개수 대신 파일별로 판단하고, 옵션이 바뀌면 처음부터 다시 합니다.
- 실행 후 첫 작업에 실패 파일이 있으면 완료 처리가 끊기던 오류를 고쳤습니다.

## 알려진 문제
- v2.2.86~v2.2.108 노트의 '알려진 문제'가 남아 있습니다.
- 이어하기는 결과 파일이 있으면 검수 실패 문서를 다시 처리하지 않고, 중단 뒤 바뀐 원본은 감지하지 않습니다. 재시작 실패로 남은 문서에는 이어하기를 제안하지 않습니다.
- 결과 목록 화면은 실제 한/글과 연결해 확인하지 않았습니다. 실제 한/글 확인은 합성 문서에 실패를 주입한 것입니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다.
