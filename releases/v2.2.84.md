# v2.2.84

## 바뀐 점
- **퀵몽땅검색: 파일명 색인·서비스 실패를 사유와 함께 표시**: 통합 검색에서 파일명 색인이 준비되지 않았거나 색인 서비스가 없을 때, 조용히 "0건"으로 끝나던 문제를 고쳤습니다. 이제 "검색을 완료하지 못했습니다"와 사유(예: 파일명 색인 준비 중)가 보입니다. 이름 색인 상태 응답(비어 있음·만드는 중·준비됨·실패)을 읽는 처리도 추가했습니다.
- **웹 화면 빌드 안정화**: v2.2.83 준비 중 찾은 끌어 놓기 코드 중복(웹 컴파일 오류)을 정리했습니다. 이 버전부터 릴리스 시험에 웹 화면 빌드 확인이 들어갑니다.

## 알려진 문제
- 이 PC처럼 관리자 색인 서비스(전체 드라이브 파일명 색인)가 설치되지 않은 환경에서는 파일명 검색이 전체 드라이브를 훑지 못합니다. 서비스는 앱 설정에서 관리자 승인을 받아 설치합니다(조사 문서 `docs/INDEX_SERVICE_STATUS_2026-11-20.md`).
- 한/글 COM 서버 오류의 근본 원인은 아직 재현하지 못했습니다.
- 설치본 화면 확인이 필요한 수정이 남아 있습니다(v2.2.83 이후 포함).

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
