# v2.2.102

## 바뀐 점
- **사진뷰·문서뷰에서 더블클릭으로 파일 열기**: 파일을 더블클릭하면 Windows 에 연결된 앱으로 엽니다. 문서뷰는 한 번 클릭하면 선택 테두리가 보입니다. 네이티브 문서뷰·사진뷰 창은 Enter 로도 열 수 있습니다.
  - 사진뷰의 한 번 클릭(크게 보기)은 그대로이며, 두 번째 클릭을 기다리느라 약 0.3초 뒤에 뜹니다. 크게 보기 화면의 사진을 더블클릭해도 열립니다.
  - 문서뷰는 목록에 보이는 형식(HWP·HWPX·XLS·XLSX·PPT·PPTX·PDF)만, 사진뷰는 사진 형식만 엽니다.

## 알려진 문제
- v2.2.86~v2.2.101 노트의 '알려진 문제'가 그대로 남아 있습니다.
- 연결 앱이 실제로 열리는 것은 설치본에서 확인하지 못했습니다(시험은 대체 실행기 사용). 네이티브 창의 실제 마우스·키 조작도 확인하지 못했습니다.
- 클라우드 전용 파일을 열면 내려받기가 일어날 수 있습니다.
- 사진뷰 묶음 격자에서 스크롤한 뒤 크게 보기를 하면 다른 사진이 보일 수 있습니다(다음 버전에서 수정 예정).

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
