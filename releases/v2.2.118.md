# v2.2.118

## 바뀐 점
- **아웃라이너(앱 안 화면)**: 명령을 처리하는 동안 친 글과 Enter·Tab 을 버리지 않고, 누른 순서대로 커서가 옮겨 간 블록에 반영합니다. 명령이 실패하면 친 글은 칸에 남기고 적용하지 않은 키 수를 알립니다.
  - 처리 중에는 블록 입력 칸 클릭과 블록 검색 제출을 받지 않습니다.
- 화면에 보이지 않는 몽땅검색 탭이 약 1초마다 ktm.exe 를 실행하던 것을 줄였습니다(상태를 5초 동안 재사용, 설정 변경 직후에는 새로 확인).
- 12-20 까지의 개발 계획 문서 추가.

## 알려진 문제
- v2.2.86~v2.2.117 노트의 '알려진 문제'가 남아 있습니다.
- 한글 음절 조합 중에 커서가 새 블록으로 옮겨 가면 글자가 중복·분리될 수 있습니다(자동 시험으로 확인 불가).
- 처리 중의 화살표·Esc·Ctrl 단축키, 친 글이 없을 때의 Backspace·Delete 는 이전처럼 무시됩니다.
- 실제 키보드와 설치본에서 확인하지 않았습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다.
