# v2.2.118

## 바뀐 점
- **아웃라이너(앱 안 화면)**: 명령을 처리하는 동안 친 글과 Enter·Tab 을 버리지 않고, 누른 순서대로 커서가 옮겨 간 블록에 반영합니다. 명령이 실패하면 친 글은 칸에 남기고 적용하지 않은 키 수를 알립니다.
  - 처리 중에는 블록 입력 칸 클릭과 블록 검색 제출을 받지 않습니다.
- **글이 사라지던 문제**: 확정하지 않은 글이 있을 때 입력 칸 바깥(빈 곳·패널·단추·다른 페이지)을 눌러도 저장한 뒤 이동합니다. 저장에 실패하면 이동하지 않고 글을 남깁니다.
- **검색 중 편집 결함**: 블록 검색으로 거른 상태에서 편집하면 다른 블록이 바뀌던 문제를 고쳤습니다. 가려진 블록이 있을 때는 블록 합치기·위아래 옮기기·가려진 하위가 있는 블록의 삭제를 막고 이유를 알립니다.
- 처리 중에 누른 Backspace·Delete 도 순서대로 반영합니다. 키를 누르고 있어도 블록이 잇달아 합쳐지지 않습니다.
- 왼쪽·오른쪽 패널과 역링크·역참조를 접고 펼 수 있습니다(상태 유지). 창이 좁으면 오른쪽을 접은 채 시작하고, 아주 좁으면 블록 옆 들여쓰기 단추를 숨깁니다.
- 화면에 보이지 않는 몽땅검색 탭이 약 1초마다 ktm.exe 를 실행하던 것을 줄였습니다(상태를 5초 동안 재사용, 설정 변경 직후에는 새로 확인).
- 12-20 까지의 개발 계획 문서 추가.

## 알려진 문제
- v2.2.86~v2.2.117 노트의 '알려진 문제'가 남아 있습니다.
- 한글 음절 조합 중에 커서가 새 블록으로 옮겨 가면 글자가 중복·분리될 수 있습니다(자동 시험으로 확인 불가).
- 처리 중의 화살표·Esc·Ctrl 단축키는 이전처럼 무시됩니다.
- 화면이 닫히거나 앱이 종료될 때의 확정 전 글 저장은 보장하지 않습니다.
- 거른 상태에서 방향키로 블록을 넘으면 검색이 풀립니다.
- 실제 키보드와 설치본에서 확인하지 않았습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다.
