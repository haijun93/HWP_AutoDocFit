# v2.2.66 (긴급 수정)

## 바뀐 점
- **설치 오류 수정**: v2.2.65 설치 마지막 단계에서 "VCRUNTIME140.dll이(가) 없어 코드 실행을 진행할 수 없습니다"가 뜨던 문제를 고쳤습니다. Rust로 만든 도우미 프로그램(몽땅검색·몽땅클립보드·자료함·검색 서비스 등)이 C 런타임을 안에 품도록 빌드해, VC++ 재배포 패키지가 없는 PC에서도 실행됩니다.
- **업데이트 설치 오류 수정**: 파일 추출 중 "_internal\VCRUNTIME140.dll 교체 … DeleteFile 실패; 코드 5"가 뜨던 문제를 고쳤습니다. 설치 전에 이 계정에서 돌고 있는 창 없는 도우미(몽땅클립보드·자료함·가상 폴더·검색 서비스·위계·몽땅검색 단축키 앱)를 먼저 끝냅니다. 이 PC에서 v2.2.65 설치로 두 오류를 모두 재현해 원인을 확인했습니다.
- 문서 변환용 Node 런타임의 보안 취약점 7건(hono·@hono/node-server)을 고쳤습니다.
- 몽땅검색 위계 판정 등 v2.2.65 이후 main의 작은 수정이 함께 들어갑니다.

- **몽땅클립보드 멈춤 수정**: 단축키(Ctrl+Shift+V)로 띄운 빠른 목록에서 그림 항목 위로 마우스를 움직이면 창이 영구히 멈추던 문제를 고쳤습니다(미리보기 창의 잠금을 두 번 잡던 오류, 이 PC에서 재현·디버거로 확인). 끌어다 놓기로 파일을 넣을 때 같은 유형의 멈춤 가능성도 함께 고쳤습니다.

## 알려진 문제
- 몽땅검색 단축키 창이 뜬 직후 곧바로 입력하면 첫 결과가 가끔 늦습니다.

## 재연 시험
- 배포 시험·경로 금지 시험 통과(이 PC), CI의 Rust 실행 파일 동적 C 런타임 검사로 확인.
- 실제 PC 설치 확인은 하지 않았습니다.
