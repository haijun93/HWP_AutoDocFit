# v2.2.86

## 바뀐 점
- **아웃라이너 새 창(Rust+Win32, 선택)**: 설정 `outliner_ui`를 'native'로 바꾸면 아웃라이너가 새 네이티브 창으로 열립니다(기본은 기존 화면). 페이지 목록·새 페이지·이름 바꾸기(링크 갱신)·삭제(되돌릴 수 있게), 오늘의 일지, 검색, `[[` 링크 자동완성, 역링크 패널, 블록 편집(Enter 커서 위치 분할·Tab 들여쓰기·삭제·합치기·TODO 토글·이동), 파일 변경 충돌 검사 저장을 지원합니다. 엔진(일지 이름 정규화·충돌 판정)도 보강했습니다.
- **앱 설정 새 창(Rust+Win32, 선택)**: 설정 `settings_ui`를 'native'로 바꾸면 설정이 새 창으로 열립니다(기본은 기존 화면). 묶음 트리·검색(2글자부터 즉시)·변경 표시·저장/되돌리기, 색·폴더·글꼴 고르기 컨트롤을 지원하고, 설정을 앱이 쓰는 동안 저장하면 충돌을 막습니다. 설정 저장소는 Rust 라이브러리(`docfit_config`)입니다.
- **몽땅클립보드 설정 새 창(선택)**: 설정 `kclip_settings_mode`를 'native'로 바꾸면 클립보드 설정이 새 창으로 열립니다. 보관 설정·캡처 종류·제외 앱·폴더별 끄기·단축키·자동 실행·켜기 흐름(15초 제한, 성공 시 창 닫힘)을 지원합니다. 단축키 창(Ctrl+Shift+V)의 다크 모드 표시 오류도 고쳤습니다.
- **탐색기 오른쪽 버튼 메뉴 '몽땅파일변환'**: 메뉴 이름이 '몽땅파일변환'으로 바뀌었고 기존 '한글편집 후처리' 키는 앱 시작 때 자동으로 정리됩니다. 선택한 파일을 모아 한 번에 처리하는 작은 Rust 프로그램(`mdm-ctx.exe`, 약 373KB)이 들어갔습니다. 설정에서 '탐색기 우클릭 메뉴'를 켠 때만 등록됩니다(Windows 11은 '추가 옵션 표시' 안).
- **하단 Dock**: 메뉴가 사이드바와 같은 4묶음 순서와 구분선으로 정렬되고, 밝게/다크 테마와 작업표시줄 위치별 배치를 지원합니다. **Dock 아이콘을 눌러도 앱이 반응하지 않던 문제**(앱 쪽에서 신호를 받는 부분이 없었음)를 고쳐 탭 열기·재클릭 닫기가 앱까지 전달되게 했습니다. 설정에서 '메뉴 표시 방식'을 Dock으로 고른 경우에만 해당합니다.
- **PDF 압축 '이미지 PDF' 방식**: 기존 글자 보존 압축으로 목표 크기에 못 미치면 이미지 PDF(쪽마다 그림으로 된 PDF)로 자동 전환할 수 있고, 화면에서 자동 전환·글자 보존·이미지 PDF 중에서 고를 수 있습니다. 이미지 PDF는 글자 선택·검색이 되지 않으며 결과에 표시됩니다.
- **퀵몽땅검색 화면 정리**: 색인 오류 화면의 겹친 글자, 통계·설정 화면 배경, 사이드바를 열 때 잘리던 옵션, 긴 파일명 말줄임, 바둑판 경로·배지 여백, 144dpi 배지 글자 위치, 칩 간격, 최소 크기 라벨, 사이드바 폭 배율을 고쳤습니다.
- **검색 성능 측정(개발자 모드)**: Everything 대 몽땅검색 1회 측정에서 질의 지연 중앙값이 몽땅검색 7.3ms 대 Everything 100.7ms(약 14배)였고, 색인 메모리는 몽땅검색이 더 컸습니다(전용 605MB 대 315MB). 이름 색인 항목당 메모리를 8바이트 줄였습니다. 분석 스크립트의 두 엔진 값이 같게 나오던 오류도 고쳤습니다.
- 내부: 설정 기본값 골든·시험 정리, 문서뷰 로그 민감 정보 마스킹, 인수 문서(HANDOVER.md) 최신화.

## 알려진 문제
- 새 창들(아웃라이너·설정·클립보드 설정)은 기본값이 기존 화면이라 사용자가 설정으로 골라야 합니다. 한글 입력(조합 중 Enter·Tab 등)·고대비·실제 폴더 대화상자·키 입력은 실제 PC에서 확인이 필요합니다.
- 하단 Dock과 몽땅파일변환 메뉴는 실제 작업표시줄·탐색기에서의 확인이 필요합니다(이 버전은 설치 시험 없이 게시).
- 색인 서비스(`HwpAutoDocFit.Index`)는 설치 프로그램이 등록하지 않습니다. 전체 드라이브 파일명 검색에는 서비스 등록·시작(관리자 승인)이 필요하고, 사용자 모드 kfind가 같은 파이프를 쓰고 있으면 서비스가 시작하지 못합니다(`docs/INDEX_SERVICE_STATUS_2026-11-20.md`).
- 한/글 COM 서버 오류(-2147417851)의 근본 원인은 아직 재현하지 못했습니다.
