# v2.2.64

## 바뀐 점
- **타임머신**: 파일명·본문검색·위계검색 결과를 더블클릭하거나 「문서 열기」를 누르면 문서가 열립니다(조사 폴더 안·지원 형식만, 실패하면 이유 표시).
- **몽땅클립보드**
  - 화면캡처 폴더(Windows 스크린샷·캡처 도구 등)를 자동으로 찾아 새 캡처를 기록합니다. 설정에서 폴더별로 끌 수 있습니다.
  - 그림 항목에 마우스를 올리거나 키보드로 고르면 미리보기가 뜹니다. 썸네일은 쉬는 시간에 미리 만들어 둡니다.
  - 일부 PC에서 단축키로 연 빠른 목록이 비어 보이던 문제(접힌 상태로 저장)를 고쳤습니다.
- **쉬는 시간 색인**: 검색 색인 갱신을 키보드·마우스를 쓰지 않는 동안 진행합니다(기본 켬, 타임머신 설정에서 끄기·기준 시간 변경).
- 쪽 수 맞춤: 쪽 나눔이 있는 붙임 쪽은 처음부터 건너뛰어 처리 시간이 줄었습니다.
- 위계검색 응답이 빨라졌습니다.
- 문서편집 > 문서 선택 화면의 「표 칸 그림을 배경으로」 버튼을 없앴습니다.

## 재연 시험
- Python·Flutter 전체 시험 통과(CI), 붙임 쪽 판정은 한/글로 결과 차이 0 확인.
- 실제 앱 화면에서의 확인은 하지 않았습니다.
