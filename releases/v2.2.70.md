# v2.2.70

## 바뀐 점
- **퀵몽땅검색(Ctrl+Alt+Space) 새 디자인과 검색 문법**: 창을 퀵몽땅클립보드와 같은 스타일로 새로 디자인했습니다(종류 표지·굵은 파일명·흐린 경로·강조된 일치 문장). 검색칸에서 정확 구문 `"…"`, 제외어 `-낱말`, 확장자 `ext:hwp,pdf`, 폴더 `path:`, 날짜 `after:`·`before:`를 쓸 수 있고, 창의 기간·형식 단추와 서로 반영됩니다.
- **검색 서비스가 파일 형식·폴더를 색인에 기록**: 위 `ext:`·`path:` 검색이 동작하도록, 문서를 색인에 넣을 때 파일 형식과 폴더를 함께 기록합니다. 업데이트 뒤 앱이 문서를 다시 보내 채웁니다.
- **이름 정리**: 단축키 창을 퀵몽땅검색(Ctrl+Alt+Space)·퀵몽땅클립보드(Ctrl+Shift+V)·퀵가상폴더(Win+Shift+F)로 부릅니다.
- **퀵가상폴더 자동 시작**: 설치하면 퀵가상폴더가 로그인 때 자동으로 켜집니다(설정에서 끈 경우는 그대로). 설정 화면에 실행 상태와 [지금 켜기]가 생겼습니다.
- **몽땅클립보드**: 켜기에 성공하면 소개 창이 닫히고 기록 관리 창이 바로 열립니다.
- **문서뷰폴더 탭**: 폴더를 고르면 문서(HWP·HWPX·PDF·Office)의 썸네일 격자를 봅니다. HWP는 한/글 없이 파일 안의 미리보기 그림을 씁니다.
- **표그림판**: A4 세로·가로 선택, '새로 그리기'(Ctrl+N), 무한 캔버스.
- **마인드맵·다이어그램**: 새 문서에서 메뉴가 사라지던 오류 수정, 전체 지우기, 도형 더블클릭으로 글 입력.
- **표템플릿**: 추진절차(가로) 모양 6·7·8 추가, 라벨 서식의 사각형 번호 기호 표시 수정, '표 칸 그림을 배경으로' 기능 삭제.
- **일괄 변환**: 보안 문서 등을 변환 전에 분류해 보고하고, 그림이 많은 정상 문서가 '압축 해제 크기 제한'으로 실패하던 오탐을 고쳤습니다.
- **텍스트 입력**: 입력하는 동안 실시간으로 변환 결과를 보여 줍니다.
- **업무 연보(개발 중 기능)**: 문서 날짜 추출, 주기 업무·폴더별 이력·기간 비교 계산 기능을 넣었습니다(화면 연결은 다음 버전).
- HWP 본문 변환 중 텍스트 출력은 Rust를 먼저 쓰고 실패하면 기존 변환기로 넘어갑니다.

## 알려진 문제
- 업데이트 직후에는 검색 색인을 다시 채우는 동안 퀵몽땅검색의 `ext:`·`path:` 검색 결과가 일부만 나올 수 있습니다(앱을 켜 두면 몇 분 안에 채워집니다).
- 퀵몽땅검색이 뜬 직후 곧바로 입력하면 첫 결과가 가끔 늦습니다.

## 재연 시험
- 전체 시험 3,216건 통과(이 PC), Rust(ktm·kagent·kvf·kfind·klib) 시험 통과.
- 퀵몽땅검색 새 디자인·한글 입력은 이 PC에서 실제 창으로 확인. 나머지 화면 변경은 설치 후 확인.
