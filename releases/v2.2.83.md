# v2.2.83

## 바뀐 점
- **PDF 편집 끌어 놓기·파일 추가 오류 수정**: 다른 탭(파일변환·문서편집 등)에서 파일을 끌어 놓아도 PDF 편집 화면이 반응해 불필요한 '열기' 창이 뜨던 문제를 고쳤습니다. 이제 PDF 편집 탭이 열려 있을 때만 반응하고, 놓은 PDF가 바로 목록에 들어갑니다.
- **PDF 압축 실패 수정**: 원본의 권한값이 음수로 저장된 PDF에서 "결과 PDF의 권한 설정이 원본과 달라 저장하지 않았습니다"로 압축이 실패하던 문제를 고쳤습니다.
- **문서뷰·사진뷰 진행 표시**: "검색 중… 99%"에서 멈춘 것처럼 보이던 가짜 진행률을 없애고, 훑은 파일 수·현재 폴더·경과 시간과 진전이 없을 때의 안내를 보여 줍니다.
- **몽땅클립보드 켜기**: 켜기 응답을 15초까지만 기다리고, 실패하면 재시도 안내와 진단 정보를 보여 줍니다. 켜짐이 확인되면 창이 닫힙니다.
- **한/글 COM 오류 안내**: 한/글 서버 오류(0x80010105, -2147417851)를 원인 후보와 조치가 있는 한국어 안내로 바꾸고, 실패한 단계와 COM 호출 이름을 작업 로그에 남깁니다.
- **내부**: Linux 검사에서 실패하던 경로 처리 시험 10건을 정리했습니다(Windows 동작은 그대로).

## 알려진 문제
- 한/글 COM 서버 오류의 근본 원인은 아직 재현하지 못했습니다. 이번 버전은 안내와 로그 개선까지입니다.
- 위 수정들은 시험으로 확인했고 실제 설치본 화면 확인은 사용자 확인이 필요합니다(이 버전은 설치 시험 없이 게시).
- 퀵몽땅검색 "합의각서" 0건 오류는 조사 중이며 이 버전에 포함되지 않을 수 있습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
