# v2.2.69

## 바뀐 점
- **몽땅검색 본문 검색 복구 seeding 즉시 실행**: 검색 서비스가 옛 형식 색인을 지우고 새로 만들어 문서 표가 비어 있는 경우(kfind status 문서 수가 0 또는 세대가 바뀌어 비었음), 앱의 kfind seeding이 유휴 시간 색인 조건(_content_idle_ctx.checkpoint)을 건너뛰어 SQLite 스냅숏에서 즉시 문서를 kfind에 보냅니다. 사용자가 PC를 사용 중이더라도 본문 검색이 장시간 비어 있지 않고 즉시 복구됩니다.
- **작업 방해 없는 낮은 우선순위 유지**: 복구 seeding 중에도 스레드 백그라운드 우선순위를 유지하고 문서 사이에 짧은 양보(time.sleep 0.01)를 두어 사용자 작업에 영향을 주지 않으며, 취소 및 앱 종료 신호를 즉시 존중합니다.
- 사용자 문서를 디스크에서 다시 열지 않고 SQLite 스냅숏 메타데이터와 문단만 사용하여 빠르고 안전하게 색인을 복원합니다.
