# v2.2.69

## 바뀐 점
- **업데이트 뒤 몽땅검색 본문 검색 빠른 복구**: 색인 형식이 바뀌어 검색 서비스 색인이 비면, 앱을 켠 뒤 20초 안에 문서를 자동으로 다시 보내 본문 검색을 되살립니다. 이전에는 PC를 쉬게 둘 때까지 기다려 본문 검색이 오래 비어 있었습니다. 다시 보내는 동안에도 PC 사용을 방해하지 않도록 문서마다 잠깐씩 쉬며, 사용자 문서는 다시 열지 않습니다.

- **표템플릿 신구대조표·모양 1 화살표 방향 수정(재발 방지)**: 미리보기에서 화살표가 위쪽으로 보이던 문제를 고쳤습니다. 한/글처럼 오른쪽을 가리킵니다. 그림 방향을 숫자로 검사하는 시험을 배포 빌드에 넣어 다시 되돌아가지 않게 했습니다.

- **몽땅검색 단축키 창 한글 입력 겹침 수정**: v2.2.68에서 "공사"를 치면 "ㄱ고공공사사"처럼 조합 중 글자가 쌓이던 문제를 고쳤습니다(이 PC 한글 입력기로 확인).
- 개발자 모드 외부 프로그램 '사진첩'의 이름을 '사진첩2'로 바꿨습니다(새 몽땅사진첩과 구별).

- **앱 검색이 새 검색 엔진을 쓰지 못하던 문제 수정(v2.2.67부터)**: 앱의 검색 연결이 예전 색인 형식 번호를 기대해 검색 엔진과 연결하지 못하고, 앱 안 검색은 옛 방식으로만 돌았으며 몽땅검색 색인도 다시 채워지지 않았습니다. 형식 번호를 맞추고, 엔진과 앱의 번호가 어긋나면 배포 빌드가 실패하도록 시험을 넣었습니다.

## 알려진 문제
- 몽땅검색 단축키 창이 뜬 직후 곧바로 입력하면 첫 결과가 가끔 늦습니다.

## 재연 시험
- 전체 시험 3,161건 통과(이 PC). 검색 서비스 문서 0건일 때만 복구가 시작되고, 평소에는 쉬는 시간 색인 조건을 지키는 시험 추가.
