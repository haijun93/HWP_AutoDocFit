# v2.2.111

## 바뀐 점
- 한번에 적용: 장평을 바꾸지 않는 경로에서는 장평 값을 읽지 않고, 재검사 대상이 정해진 순회는 필요한 곳까지만 돕니다. 합성 문서에서 결과는 같았고 한/글 호출이 줄었습니다(자간 단계 약 6~17%, 재검사 0~3%). 처리 시간 단축은 확인하지 못했습니다.
- 사이드바와 메뉴별 별도 창(선택해야 켜짐): 설정·파일변환·파일명 변경·문서뷰·사진뷰·아웃라이너 Rust 창 기능을 늘렸습니다. **기본 화면은 그대로입니다.** 켜려면 실행 인자 --sidebar 또는 설정 파일의 launch_mode="sidebar" 를 씁니다.
- 저장하지 않은 편집이 있으면 앱을 닫기 전에 확인하고, 변환 중에 닫으면 중단할지 묻습니다(기본 화면에도 적용).

## 알려진 문제
- v2.2.86~v2.2.110 노트의 '알려진 문제'가 남아 있습니다.
- Rust 사진뷰에는 사진대지 HWPX, 날짜·폴더·카메라·위치 묶음 보기, 편집 미리보기가 없습니다.
- Rust 문서뷰·사진뷰는 v2.2.110 의 목록 DB 를 쓰지 않고 직접 검색합니다.
- 사이드바 방식을 고르는 설정 화면은 아직 없습니다.
- 실제 설치·업데이트·제거, 자동 실행 등록, 실제 한글 입력, 다중 모니터는 확인하지 않았습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다.
