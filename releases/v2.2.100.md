# v2.2.100

## 바뀐 점
- **아웃라이너 블록 참조·페이지 관리**: `((블록 id))`·`(((블록 id)))` 블록 참조를 넣고(입력 중 후보 자동완성), 어떤 블록이 이 블록을 참조하는지(역참조) 볼 수 있습니다. 페이지 이름을 바꾸면 다른 파일의 `[[옛이름]]` 링크가 `[[새이름]]`으로 한꺼번에 바뀌고(실패하면 원래 이름으로 복구), 페이지를 지우면 휴지통으로 보냅니다(이동에 실패하면 지우지 않고 오류로 알립니다). 모두 실행 취소가 됩니다. Win32 아웃라이너와 Flutter 화면 모두 연결했습니다. 시험: `outliner_core` 85건, `outliner_win` 132건(차이 0 하네스 포함), Flutter 14건, 서비스 14건. **한글 입력(IME) 중 동작과 팝업의 실제 화면은 확인하지 못했습니다.**
- 내부(기본 동작 불변): **hwpx_fmt 직접 처리기 5종 중 4종 Rust 이식**(옵션, 기본 꺼짐). 합성·시험 문서 하네스 247쌍과 기존 1,099문서 2,751쌍에서 Python 결과와 차이가 없었습니다. 다만 ALLQA 시험 문서에는 이 처리기가 적용되는 대상이 없어 실제 속도 효과는 확인하지 못했습니다.
