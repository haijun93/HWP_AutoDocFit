# v2.2.38

## 바뀐 점
- 개발자 모드 사이드메뉴에 별도 프로그램 3종 연결(사용자 요청): '사진첩'(mongdangview — NeeView 포크, MIT), '아웃라이너'(mongdangoutliner — Logseq 포크, AGPL-3.0), '사진관리'(mondangpics — digiKam 포크, GPL-2.0). 앱 폴더 tools/ 또는 설정에서 지정한 실행 파일을 별도 프로그램으로 실행하고, 없으면 설치 안내
- 보안: 앱 화면에 콘텐츠 보안 정책(CSP) 적용(외부 출처 차단)
- 세 프로그램의 라이선스 준수 방법과 배포 방식 문서(docs/EXTERNAL_APPS.md)

## 배포 검증
- CI 통과(실행 42399697661, 화면 CSP를 켠 배포 파일 실행 확인 포함), GitLab 보안 검사 사전 통과, Python 2570개·Flutter 487개 시험 통과
