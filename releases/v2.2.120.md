# v2.2.120

게시하지 않은 v2.2.119 의 변경을 모두 포함합니다(`releases/v2.2.119.md`).

## 바뀐 점
- **통합 검색(기본 끔)**: 몽땅검색 탭의 [통합 보기]를 켜면 파일명·위계·본문 결과를 한 번에 봅니다. 전체 결과에서 순위를 매기고 나눠 불러옵니다. 폴더 이름 결과도 나옵니다.
- 퀵몽땅검색에서 파일명 검색이 실패하면 '0건'으로 보이던 것을 고치고, 위계·본문 결과는 보여 줍니다.
- **퀵몽땅검색 다크 테마**: 고대비 → 퀵몽땅검색의 밝게·어둡게 → 앱 테마 → Windows 순으로 따릅니다. 따로 고른 적이 없으면 밝게 보일 수 있습니다.
- **아웃라이너 상주 엔진**: 명령 처리 프로그램을 계속 띄워 두고 씁니다. 설정 `outliner_resident_engine: false` 또는 환경 변수 `DOCFIT_OUTLINER_RESIDENT=0` 으로 끕니다.
- **몽땅검색 '이름 찾기'**: 결과를 더블클릭·[문서 열기]로 열 수 없던 것을 고치고, 경로·형식 칸을 채웁니다. 폴더 행은 '폴더'로 표시합니다.
- [색인 초기화]가 앱이 만든 문서 색인을 지우지 못하던 것을 고쳤습니다.
- 연관 검색(`;`)에서 파일명 결과가 늘 0건이던 것을 고쳤습니다.
- (v2.2.119) 색인 서비스 없이 바탕 화면·문서·다운로드 파일명 검색, 설정에서 전체 드라이브 색인 켜고 끄기, [색인 초기화], 폴더 이름 검색, 첫 실행 지연·`not_connected` 수정, 스캔 PDF 변환의 OCR 사용, 「표 칸 그림을 배경으로」 단추 제거.

## 알려진 문제
- v2.2.86~v2.2.119 노트의 '알려진 문제' 가운데 위에서 고쳤다고 적지 않은 것은 남아 있습니다.
- 색인 서비스(`HwpAutoDocFit.Index`)를 설치해 둔 PC는 설정 > 전체 드라이브 색인에서 끄고 다시 켜야 새 색인 프로그램을 씁니다.
- 통합 검색의 첫 표시가 목표 16ms 를 넘습니다(합성 자료 측정 20.7/17.8ms).
- 블록이 매우 많은 아웃라이너 문서는 명령 반응 0.2초 목표를 넘을 수 있습니다.
- 몽땅검색 '이름 찾기'는 파일 형식 필터를 적용하지 않고, 결과 미리보기는 발췌문만 보입니다.

## 재연 시험
- 합성 자료의 자동 시험만 했습니다. 설치본, 실제 화면, 다크 테마, 한글 입력, UAC 서비스 설치는 확인하지 않았습니다.
