# v2.2.98

## 바뀐 점
- **PDF 편집 탭 화면 개편**: 큰 점선 드롭 영역, 파일 정보 카드, 도구 칩 막대, 쪽 썸네일 격자(회전·삭제·순서 변경), 고정 작업 패널로 바꿨습니다. PDF를 화면에 끌어다 놓거나 파일 선택 창으로 열 수 있습니다. 쪽 정보를 읽는 중·실패·다시 시도 상태를 보여 줍니다. 위젯 시험 19건과 Flutter 전체 824건을 통과했습니다. 실제 앱(WebView2)에서의 끌어다 놓기·파일 선택 창·글꼴 표시는 확인하지 못했습니다.
- 내부(기본 동작 불변, 앱에 연결되지 않음): **Markdown → HWPX 생성기**(kordoc 대체 준비). 제목·항목기호·표·강조·줄바꿈·그림·4~6단 제목·코드·링크 표시를 지원하며, 합성 19종에서 한/글 2020 열림·저장 19/19입니다. 측정·설계 문서(`docs/KORDOCC*`, `docs/PDFUI3_*`)를 함께 담았습니다.

## 알려진 문제
- v2.2.86~v2.2.97 노트의 '알려진 문제'가 그대로 남아 있습니다.
- PDF 편집 화면의 시각적 모양(글꼴 깨짐 여부 포함)은 화면으로 확인하지 못했습니다.
- Rust 몽땅검색엔진 통합 작업(검색 backend 계약·Rust 색인)은 klib의 기존 시험 4건이 깨져 이번 버전에서 제외했고, 수정 뒤 다음 버전에 담습니다.

## 재연 시험
