# v2.2.95

## 바뀐 점
- **아웃라이너 실행 취소/다시 실행**: Ctrl+Z, Ctrl+Y(또는 Ctrl+Shift+Z)와 되돌리기·다시 실행 단추를 넣었습니다(Flutter 탭, Win32 창은 단축키). 편집 직전 문서를 한 단계로 쌓고(200단계·32MiB 한도), Enter 한 번(글 확정+줄 추가)은 한 단계로 묶입니다. 입력 칸에 확정하지 않은 글이 있거나 한글 조합 중이면 칸 자체의 되돌리기에 맡깁니다.
- **아웃라이너 Logseq 키 정렬과 다중 블록 선택**: 블록 이동이 Logseq와 같은 `Alt+Shift+↑/↓`로 바뀌었고 `Alt+↑/↓`·`Shift+↑/↓`는 블록 선택 확장입니다. 선택한 블록들을 한꺼번에 삭제·들여쓰기·내어쓰기·접기·복사/잘라내기·이동할 수 있고, 되돌리기는 한 단계입니다. **기존에 `Alt+↑/↓`로 블록을 옮기던 분은 키가 바뀌었음에 주의해 주세요.**
- **몽땅클립보드 켜기(Win32 설정 창)**: 켜기가 15초에 실패로 끝나지 않고 상태를 조회하며 최대 60초 기다립니다. 실제로 실행 중이면 성공으로 표시하고, 같은 버전이 이미 실행 중이면 재시작하지 않습니다. 첫 실행에서 새 프로세스의 준비 신호를 기다리는 시간을 3초에서 60초로 늘렸고, 구간별 시간을 `lifecycle-timings.jsonl`에 기록합니다.
- **위계(제N장·절·항목) 판정 개선**: 앞 기호가 붙은 `[붙임 1] 제1장`·`【별표】 제2장` 인식, 장 제목이 있는 1×1·1행 표 안 문단의 위계 판정, 표 안 문단의 이중 기록 방지, HWP(바이너리) 본문의 텍스트 기반 위계 판정을 추가했습니다. **위계 판정 규칙이 바뀌어 이미 만들어 둔 본문 색인은 다시 만들어야 새 규칙이 반영됩니다**(자동 재색인은 이번에 넣지 않았습니다).
- **업무 연보**: 연간 1~53주차 문서 작업량 추이 SVG 차트를 만들었습니다(`주차별_문서수.svg`, 아직 앱 화면에는 연결되지 않았습니다).
- **한번에 적용 단계 선언 표(내부, 동작 불변)**: 단계 목록과 순서를 데이터로 선언하는 부품을 만들고, 현재 결과와 같음을 모드 4종×옵션 조합 2,048개 입력에서 확인했습니다(엔진에는 아직 연결하지 않음).
- **내부(앱에 연결되지 않은 Rust 이식)**: HWPX 직접 처리기 19종 중 14종(표 두 글자 칸·표 날짜 칸·개요 첫 빈칸·쪽 번호·자간 초기화·별표 위첨자·붙임 글꼴·콜론 라벨·빈 줄·강조 낱말·표 칸 너비·기본 표 서식·정렬 재확인·연결 부호 탭)을 `hwpx_fmt`로 옮겼고, 합성·시험 문서 1,099건에서 파이썬 결과와 차이 0, 속도 2.8~11배입니다.
- 내부 문서: 한번에 적용 구조 개선 설계, 업무 연보 카드 계획, kordoc 의존 줄이기 2·3단계 설계, 위계 추출 확대 설계.

## 알려진 문제
- v2.2.86~v2.2.94 노트의 '알려진 문제'가 그대로 남아 있습니다(앱이 실행 중이면 설치가 중단됩니다 — 설치 전에 앱·몽땅검색·퀵가상폴더를 모두 닫아 주세요, 문서뷰 '0개 문서' 원인 미확정 등).
- 아웃라이너 실행 취소·다중 선택은 한글 입력기(IME) 조합 중 동작과 Windows 시스템 클립보드를 실제 PC에서 확인하지 못했습니다. Win32 창에는 되돌리기 단추가 없고 단축키만 있습니다. 접힘은 되돌리기 대상이 아닙니다.
- 클립보드 켜기의 실제 지연 원인은 이 PC에서 측정하지 못했습니다(후보만 좁힘).
- 아웃라이너의 드래그 이동·블록 참조 화면은 아직 없습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
