# v2.2.85

## 바뀐 점
- **문서뷰·사진뷰 스캔 속도(Rust 전환)**: 폴더 스캔을 Rust 스캐너로 바꿨습니다. 같은 범위(바탕 화면 약 7만 4천 파일)에서 Python 5.19초가 Rust 0.19초로 약 27배 빨라졌고 결과는 같습니다(차이 0). 파일명 색인 서비스가 준비돼 있으면 거기서 바로 목록을 가져오고, 없으면 Rust 스캐너, 그것도 안 되면 기존 Python 스캔으로 자동으로 되돌아갑니다. 마지막 스캔 결과를 저장해 두었다가 화면을 열면 먼저 보여준 뒤 새 결과로 바꿉니다. 개발 작업 폴더·빌드 산출물은 기본 제외됩니다.
- **문서뷰 썸네일 크기 조절**: 사진뷰처럼 문서뷰에도 썸네일 크기 슬라이더가 생겼고, 두 화면이 같은 부품을 씁니다.
- **사이드바 개선**: 왼쪽 사이드메뉴를 묶음(문서 작업·그리기·찾기·자료·변환·도구)으로 나누고 접힘 모양을 다듬었습니다. 화면 위쪽에 하위 화면용 가로 탭, 오른쪽에 빠른 실행 막대(이름 풍선 도움말·알림 배지·보이기/숨기기)가 생겼습니다.
- 내부: 앱 설정·아웃라이너·오른쪽 버튼 메뉴의 Rust+Win32 전환 설계 문서를 추가했습니다.

## 알려진 문제
- 위 수정들은 시험으로 확인했고 실제 설치본 화면 확인은 사용자 확인이 필요합니다(설치 시험 없이 게시).
- 설치본에 Rust 스캐너(klib.exe)가 들어 있는지 이번 CI 산출물에서 확인해야 합니다. 없으면 자동으로 Python 스캔이 쓰여 속도 개선이 적용되지 않습니다.
- 이 PC처럼 관리자 색인 서비스가 없는 환경에서는 전체 드라이브 파일명 색인을 쓰지 못합니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
