# v2.2.116

## 바뀐 점
- **아웃라이너(앱 안 화면)**: 글을 입력할 때마다 다른 창이 떴다 사라지던 문제를 고쳤습니다. 명령 하나의 시간이 이 PC 측정에서 약 1.3초에서 0.07초(엔진 실행 부분)로 줄었습니다.
- 처리 중에 누른 Tab·Shift+Tab 을 버리지 않고 끝난 뒤 적용합니다.
- 같은 원인의 창 깜빡임을 PDF 편집, 위계 분석, 서식 엔진, 문서 변환, 성능 측정에서도 없앴습니다.
- 사진 DB: 정션 같은 우회 경로로 접근해도 같은 사진을 두 번 기록하지 않고 기존 행을 씁니다.
- 문서뷰 목록 비교: 바뀌지 않은 행의 재저장을 없애 다시 열기·변경 반영이 빨라졌습니다(합성 6.5만 건 측정).
- 시험 안정화, 사용자 확인 목록 문서 추가.

## 알려진 문제
- v2.2.86~v2.2.115 노트의 '알려진 문제'가 남아 있습니다.
- 아웃라이너 처리 중에 친 글자와 Enter 는 여전히 무시될 수 있습니다(처리 시간이 짧아져 가능성은 줄었습니다).
- 설치본에서 실제 입력으로 확인하지 않았습니다. 한글 입력 조합 중의 동작은 자동 시험만 했습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다.
