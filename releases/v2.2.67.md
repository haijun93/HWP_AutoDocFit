# v2.2.67

## 바뀐 점
- **HWP 본문을 Rust로 직접 읽기**: 자료함·몽땅검색 색인이 .hwp 본문을 외부 변환기 없이 직접 읽습니다. 문서당 약 40배 빨라졌고, 읽지 못하는 문서(배포용·암호 등)는 기존 변환기로 자동 대체합니다.
- **몽땅클립보드 빠른 목록 줄 버튼**: 그림 항목에 [붙임사진 편집으로 보내기], 글·파일·폴더·웹 항목에 [연결 프로그램으로 열기] 버튼을 고정·삭제 버튼 왼쪽에 추가했습니다.
- **검색 형식 확대**: csv·xlsm 본문과 md 문서를 검색합니다.
- **검색 엔진 확장**: 문서·폴더·기간 단위로 범위를 좁혀 찾는 기능, 형식·삭제 표시·문장 역할 구분, 자주 다룬 주제 순위표(자동 완성·관련어 추천용)를 엔진에 넣었습니다. 화면 연결은 다음 버전부터입니다.
- 몽땅클립보드 캡처 폴더에서 Xbox Game Bar 항목을 뺐습니다.
- 위계 판정을 Rust 엔진 우선으로 바꾸었습니다.

## 알려진 문제
- 몽땅검색 단축키 창이 뜬 직후 곧바로 입력하면 첫 결과가 가끔 늦습니다.

## 재연 시험
- 전체 시험 3,156건 통과(이 PC), Rust(klib·kfind·kagent·ktm) 시험 통과.
- HWP 사본 21개로 Rust 읽기와 기존 변환기 대조: 기존 변환기가 읽은 글자 조각을 모두 포함.
