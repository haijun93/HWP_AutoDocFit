# v2.2.104

## 바뀐 점
- **단축키 검색창(퀵몽땅검색) 화면 겹침 수정**: 화면 배율 100~200%에서 글자 크기를 실측해 배치합니다.
- 내부(기본 동작 불변): DOCX·XLSX·PPTX·HTML 입력 변환의 자체 구현과 선택형 라우팅. 기본은 kordoc 그대로이며 앱 화면에는 연결하지 않았습니다.
- 개발: 변환 시험 자료 비교를 압축 구현과 무관하게 고치고, 의존성 점검의 추출 오류를 고쳤습니다.

## 알려진 문제
- v2.2.86~v2.2.103 노트의 '알려진 문제'가 남아 있습니다.
- 의존성 점검에서 확인된 취약점(lopdf, quick-xml 등)은 아직 해소하지 않았습니다.
- 실제 모니터의 배율 전환 화면은 확인하지 못했습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
