# v2.2.107

## 바뀐 점
- **아웃라이너 편집 동작**: 빈 줄에서 Enter 를 누르면 항상 한 단계 내어쓰기가 됩니다(최상위 빈 줄은 새 줄). 위치에 따른 Enter(나누기·위에 새 줄·첫 하위 항목), Shift+Enter 줄바꿈, Backspace·Delete 병합, Tab·Shift+Tab, 블록 선택과 이동을 Logseq 방식에 맞췄습니다.
  - 바뀐 키: Ctrl+Enter = TODO 순환(접기는 Ctrl+↑/↓), 편집 중 Alt+↑/↓ = 블록 선택(이동은 Alt+Shift+↑/↓), 여러 줄 붙여넣기 = 줄마다 블록.
- **아웃라이너 새 창(설정의 화면 방식을 새 창으로 바꾼 경우)**: 왼쪽·오른쪽 사이드바와 상단 막대, 불릿·접기·줌·상위 경로·끌어 옮기기, 슬래시 명령·자동 완성·빠른 검색·명령 팔레트. 앱 안 화면에는 아직 없습니다.

## 알려진 문제
- v2.2.86~v2.2.106 노트의 '알려진 문제'가 남아 있습니다.
- 실제 한글 입력 조합 중의 Enter·Tab, 설치본에서의 동작은 확인하지 못했습니다.
- 앱 안 화면은 명령마다 편집 엔진을 새로 실행해, 빠르게 연달아 입력하면 글자가 빠지거나 Enter 가 무시될 수 있습니다(이전부터 같은 구조).
- 새 창의 즐겨찾기·최근 목록·방문 이력은 창을 닫으면 사라집니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
