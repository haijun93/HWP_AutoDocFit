# v2.2.94

## 바뀐 점
- **한번에 적용이 빨라졌습니다(결과 문서는 그대로)**: 줄 검사 기억(한/글에서 읽은 줄 경계를 편집 전까지 재사용)을 기본으로 켰습니다. 같은 시험 문서 6건으로 개선 전과 비교해 전체 처리 시간이 **638.7초 → 355.2초(-44.4%)**, 한/글 호출 횟수는 8.1% 줄었고, 저장된 5개 결과는 문단·텍스트·서식이 개선 전과 모두 같았습니다(표가 많은 1건은 개선 전·후 모두 한/글 열기 오류로 비교 불가). 시험 PC가 완전히 한가한 상태는 아니었고 문서 6건·1회 측정이라 실제 PC에서는 달라질 수 있습니다. 문제가 있으면 환경변수 `DOCFIT_SPACING_MEMO=off`로 끌 수 있습니다.
- **진행 표시가 실제 시간 비중을 따릅니다**: 한번에 적용의 진행 막대를 단계별 실제 소요 비중(자간 약 40%, 내어쓰기 약 24% 등)으로 가중하고 '남은 시간'(계산 중 → 약 3~5분 범위 표시)을 보여 줍니다.
- **한번에 적용 옵션 화면 정리**: 핵심 옵션(자간 조정 포함·표 제외)만 바로 보이고 나머지는 '고급 설정'으로 접었습니다(켜 둔 개수 표시). 세부 작업은 묶음별로 접고 묶음 전체 켜기/끄기, '28개 중 N개 사용' 요약을 넣었습니다. 설정 키와 기본값은 그대로입니다.
- **사진뷰 오류 수정**: 여러 드라이브(C:·E: 등)를 쓰는 PC에서 사진뷰가 `Paths don't have the same drive` 오류로 목록을 못 불러오던 문제를 고쳤습니다.
- **문서뷰 '0개 문서' 보완**: 폴더 순회 오류를 빈 목록으로 숨기지 않고 사유를 보여 주며, 폴더 열거 실패를 성공한 빈 스캔으로 처리하지 않습니다. 이전에 저장된 빈 스캔 결과는 초기 화면에 쓰지 않습니다. 드라이브가 다른 경로 비교 16곳을 안전하게 바꿨습니다.
- **몽땅클립보드 켜기 개선**: 켜기가 '즉시 응답 + 상태 조회'로 바뀌어 15초 제한에 걸려 '켜지 못했습니다(enable timeout)'가 뜨던 문제를 줄였습니다. 단추가 '켜는 중…(단계)'로 바뀌고, 시간이 오래 걸려도 실제로 켜져 있으면 성공으로 표시합니다. 이미 같은 버전이 실행 중이면 재시작하지 않습니다.
- **아웃라이너 입력 유실 수정**: 입력 중 Tab/Shift+Tab을 누르면 입력한 글자가 저장되지 않던 문제를 고쳤습니다(v2.2.93의 Enter 줄 이동 수정에 이어).
- **설치 누락 안내**: 새 창 프로그램이 설치되지 않은 경우 '설치가 완료되지 않았을 수 있습니다. 앱을 모두 닫고 설치 프로그램을 다시 실행해 주세요'를 안내하고, 설치 프로그램이 시작·끝·롤백과 설치 직후 7종 존재 여부를 `install.log`에 기록합니다. 빌드(CI)에서도 새 창 프로그램이 꾸러미에 들어갔는지 확인합니다.
- 내부: `hwpx_fmt`(표 두 글자 칸·표 날짜 칸·개요 첫 빈칸·쪽 번호·자간 초기화 처리기의 Rust 이식 프로토타입, 앱에는 아직 연결하지 않음), 한/글 2프로세스 동시 처리 측정(30.6% 단축, 안정성 근거 부족으로 적용 보류) 문서.

## 알려진 문제
- v2.2.86~v2.2.93 노트의 '알려진 문제'가 그대로 남아 있습니다.
- **앱이 실행 중이면 설치 프로그램이 파일을 교체하지 못하고 중단됩니다.** 설치 전에 앱·몽땅검색·퀵가상폴더를 모두 닫아 주세요. 이 경우 일부 새 창 프로그램이 빠진 채로 남을 수 있으니, 아웃라이너 등 새 창이 '프로그램을 찾을 수 없습니다'로 뜨면 앱을 닫고 다시 설치해 주세요.
- 몽땅클립보드 켜기가 느렸던 실제 원인은 이 PC에서 측정하지 못했고(후보만 좁힘), Win32 설정 창의 켜기에는 15초 제한이 남아 있습니다.
- 문서뷰 '0개 문서'의 정확한 원인은 설치본에서 확인이 필요합니다. 같은 증상이 계속되면 알려 주세요.
- 한번에 적용 시험 문서 일부(TXT 변환)에서 '원문 보존 검사'가 개선 전부터 통과하지 못합니다(변환 과정의 문자 차이일 수 있어 원인 분석 전).
- 아웃라이너는 다중 블록 선택·드래그 이동·문서 단위 실행 취소·블록 참조 화면이 Logseq에 비해 아직 부족하고, 블록 이동 단축키(Alt+↑/↓)가 Logseq의 Alt+Shift+↑/↓와 다릅니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
