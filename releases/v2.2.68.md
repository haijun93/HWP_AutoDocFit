# v2.2.68 (긴급 수정)

## 바뀐 점
- **몽땅검색 본문 검색 오류 수정**: v2.2.67로 업데이트한 뒤 몽땅검색 단축키 창 본문 검색에 "index format version 3, expected 4"만 나오던 문제를 고쳤습니다. 색인 형식이 바뀐 경우 검색 서비스가 첫 검색 때 바로 새 형식으로 다시 만들고, 그동안 단축키 창은 "색인을 새 형식으로 다시 만드는 중입니다" 안내를 보여줍니다(앱 안 검색은 영향 없었음).
- **몽땅검색 단축키 창 기능 추가**: 입력 중 자동 완성, 검색어가 없을 때 주요 주제 단추, 기간(오늘·이번 주·이번 달·올해·직접)과 폴더로 좁혀 찾기.
- 검색어를 자동 완성으로 바꿀 때 단축키 창이 종료되던 문제를 고쳤습니다.
- 업무 연보: 짧은 제목끼리 비슷한 문서를 묶는 판정을 낱말 단위로 보완했습니다.

## 알려진 문제
- 몽땅검색 단축키 창이 뜬 직후 곧바로 입력하면 첫 결과가 가끔 늦습니다.

## 재연 시험
- 이 PC에서 옛 형식 색인으로 오류를 재현하고, 수정판 시험(옛 형식 색인이 첫 검색에 새로 만들어짐) 통과.
- 단축키 창 실제 표시 확인: 결과 목록·자동 완성·폴더 거르기(합성 색인 3,000건). 검색 처리 p95 2.6ms 이하, 상주 전용 메모리 증가 0.1MB.
