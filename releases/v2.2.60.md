# v2.2.60

## 바뀐 점
- **배포판에서도 검색 결과의 상위 경로와 새 위계 판정이 적용됩니다**: v2.2.59에서 배포판은 빠른 내부 엔진으로 색인해 텍스트·Markdown·Word 문서의 위계 판정이 빠졌던 문제를 고쳤습니다. 업데이트 뒤 첫 실행 때 색인이 배경에서 다시 만들어집니다.
- **작업 중단이 확실히 먹힙니다**: 작업을 시작한 직후나 단계 사이에 누른 "작업 중단"이 사라지지 않고 반영됩니다.
- **작업이 끝난 직후에도 바로 다시 시작할 수 있습니다.** 작업이 비정상으로 끝나면 화면이 "실행 중"으로 멈춰 있지 않고 실패로 알려 준 뒤 잠금을 풉니다.
- **남겨 둔 결과 창을 보호합니다**: "자동 닫기"를 끄고 남겨 둔 결과 한/글 창은 다음 작업의 정리 과정에서 함께 닫히지 않습니다. 저장하지 않은 편집 내용을 잃지 않습니다.
- **닫기를 연달아 눌러도 확인 없이 꺼지지 않습니다**: 닫기 확인 창이 떠 있는 동안 30초 안의 닫기는 무시합니다. 앱이 정말 멈췄을 때는 30초 뒤 다시 닫으면 끌 수 있습니다.
- **파일 변환 결과를 사실대로 알려 줍니다**: 변환된 파일이 없으면 "변환된 파일이 없어요 — 건너뜀 N, 실패 M"으로, 건너뛴 파일은 실패와 구분해 "건너뛰었어요"로 보여 줍니다.
- **시작이 조금 빨라졌습니다**: 첫 화면 전에 필요 없는 기능(업데이트 확인·일괄 서식·교정 등)은 처음 쓸 때 불러옵니다(개발 환경 측정 불러오기 시간 1,010ms → 895ms).
- 한국어 Windows에서 실행 중인 프로그램 목록을 읽을 때 한글 창 제목 때문에 생기던 오류를 고쳤습니다.

## 알려진 문제
- 배포판의 본문 색인은 위계를 다시 매기는 단계가 더해져 조금 느려졌습니다(300문서 기준 약 4.6초 → 6.8초).
- 위계검색 응답이 v2.2.59 이전보다 약 13% 느린 상태가 그대로입니다.

## 재연 시험
- Python 전체 시험 2,875건 통과(11건 건너뜀).
- 한/글 2020 실기: 시작 3초·0.1초 뒤 중단, 정상 완료 직후 재시작, 남겨 둔 결과 창 보호, 닫기 연타 보호를 지정 시연 문서 사본으로 확인했습니다. 결과 창에 저장하지 않은 편집이 실제로 남는지, 비교 보기를 켠 경우는 확인하지 않았습니다.
- 배포 exe 화면에서의 확인은 이번 버전에서 하지 않았습니다.
