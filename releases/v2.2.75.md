# v2.2.75

## 바뀐 점
- **사이드메뉴에서 쓸 메뉴 고르기**: 설정에서 메뉴별로 켜거나 끌 수 있고, 선택은 저장됩니다. 끈 메뉴는 사이드메뉴에서 숨겨지며 이미 열려 있는 작업 화면은 유지됩니다. 문서편집 메뉴는 항상 켜져 있습니다.
- **IPC 오류 응답과 작업 상한**: 연결 수 초과와 요청 크기 초과에 오류 응답을 보내며, 동시에 실행하는 작업 수에 상한을 둡니다. 초과한 작업 요청은 오류로 응답합니다.
- **회귀 시험 추가**: 표템플릿 화살표 미리보기와 내보내기 방향 비교, 빈 문단 20개의 여백 보존, 숨긴 사이드메뉴와 네이티브 IPC 관련 시험을 추가하거나 보완했습니다.
- **개발 문서 추가**: Tk·레거시 잔존 사용처 목록과 제거 순서, 업데이트 서명 키 활성화 점검 목록, Python 의존성 해시 잠금 검토 문서, 변경 전후 성능 비교 절차를 추가했습니다.
