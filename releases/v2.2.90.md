# v2.2.90

## 바뀐 점
- **선택형 Win32 창 2종 추가(기본값은 기존 화면)**: 파일변환(`conversion_ui`)과 파일명 일괄변경(`rename_ui`)을 `native`로 바꾸면 새 창이 열립니다. 이번 단계는 뼈대입니다. 파일변환 창은 대상 선택·파일 목록·변환 시작(기존 엔진 호출)까지, 파일명 변경 창은 규칙 미리보기와 충돌 표시만 하며 실제 이름 변경은 하지 않습니다.
- **Dock 자동 숨김(선택)**: 설정 `dock_auto_hide`를 켜면 겹치는 창이 있을 때 Dock이 숨고, 화면 가장자리 2px 위로 마우스를 올리면 다시 나타납니다. 기본값은 꺼짐(현재 동작 유지)입니다. 슬라이드 애니메이션은 아직 없습니다.
- **설치 기록 추가**: 설치·제거 중 정리(`taskkill`) 실패와 부가 프로그램 시작 단계를 `%LOCALAPPDATA%\HwpAutoDocFit\logs\install.log`에 남깁니다. 기록 실패가 설치를 멈추지 않습니다. 설치 동작 자체는 바뀌지 않았습니다.
- 내부: 설치 프로그램 구성요소 선택 설계 문서, v2.2.89 사용자 확인 체크리스트 추가.

## 알려진 문제
- v2.2.86~v2.2.89 노트의 '알려진 문제'가 그대로 남아 있습니다.
- Dock 자동 숨김의 다중 모니터·최대화 창 동작은 실제 PC에서 확인하지 못했습니다.
- 설치 기록은 컴파일만 확인했고 설치·제거 실기 시험은 하지 않았습니다(사용자 지시).

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
