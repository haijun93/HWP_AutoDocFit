# v2.2.106

## 바뀐 점
- **앱 안 문서뷰·사진뷰 속도**: 파일을 찾는 대로 목록에 보여 줍니다. 사진은 검색할 때마다 촬영 정보를 다시 읽던 문제를 고쳤습니다. 합성 시험에서 사진 1만 장의 첫 표시는 209초에서 0.13초, 다시 검색 완료는 178초에서 3.7초가 됐습니다.
- **네이티브 문서뷰·사진뷰 창**: 다중 선택(Shift·Ctrl·Ctrl+A), 복사·폴더로 복사·이동·이름 변경·휴지통 삭제, 오른쪽 메뉴.
- 문서뷰 오른쪽 메뉴의 문서편집·파일 변환에서 XLS·PPTX·HML 을 쓸 수 있습니다(PPT 는 지원하지 않음).
- 고침: 본문 검색이 디버그 빌드에서 간헐적으로 종료되던 문제, 자료함 색인·이름 바꾸기의 XML 참조 처리(DTD·정의되지 않은 참조가 있는 문서는 거부).
- PDF 편집에서 쓰지 않는 날짜 라이브러리를 뺐습니다.

## 알려진 문제
- v2.2.86~v2.2.105 노트의 '알려진 문제'가 남아 있습니다.
- 사진이 많으면 첫 촬영 정보 정리가 오래 걸립니다(약 19만 장에서 28분). 그동안 목록은 보입니다.
- 사진뷰의 새로고침·폴더·카메라·위치 보기는 검색이 끝날 때까지 대기합니다.
- 색인 서비스가 이전 버전 프로세스로 남아 있으면 목록 조회가 느린 방식으로 넘어갑니다. 설치 뒤 PC 를 다시 시작해 주세요.
- 설치본에서의 속도·네이티브 창 조작·실제 휴지통은 확인하지 못했습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
