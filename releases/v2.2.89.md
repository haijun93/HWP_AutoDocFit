# v2.2.89

## 바뀐 점
- **문서뷰·사진뷰 Win32 창에 탐색기(셸) 썸네일 연결**: 보이는 칸부터 먼저 만드는 4개 작업 스레드와 64MiB 캐시로 썸네일을 공급합니다. 합성 JPEG 20장(4000×3000) 실측에서 4개 스레드가 Pillow보다 약 32% 빨랐습니다. 새 창은 설정 `docview_ui`·`photoview_ui`를 `native`로 바꿀 때만 쓰이며, 기본값은 기존 화면입니다.
- **문서뷰·사진뷰·설정·아웃라이너 Win32 창 앱 연결**(선택형): 제외 폴더 편집, 실제 `klib scan` 연동, 설치본 번들과 CI 시험을 포함합니다.
- **실행 파일 크기 감소**: `kfind`·`outliner`·`pdf-edit`·`qms_bench`에 릴리스 프로필(LTO·strip)을 넣어 이 PC 기준 약 61~80% 줄었습니다(`hierarchy`는 약 14%). `klib`는 사용하지 않는 검색 기능을 빼 약 3% 줄었습니다. 시작 시간은 나빠지지 않았습니다.
- **색인 서비스 오류 로그**: `kfind` 서비스의 오류·패닉을 데이터 폴더의 `logs/kfind-service.log`(256KiB 회전)에 남깁니다.
- 탐색기 오른쪽 버튼 메뉴 전달 경로(이름 있는 파이프) 보강.

## 알려진 문제
- v2.2.86~v2.2.88 노트의 '알려진 문제'가 그대로 남아 있습니다(새 창·Dock·탐색기 메뉴 실제 PC 확인 필요, 한/글 COM 오류 근본 원인 미해결).
- 크기 감소 수치는 개발 PC(GNU 툴체인) 기준이며 설치본(MSVC)에서의 값은 CI 빌드 후 확인이 필요합니다.
- 셸 썸네일은 PDF·TXT에 일반 아이콘이 나올 수 있습니다(미리보기 처리기에 따라 다름).

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
