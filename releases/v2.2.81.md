# v2.2.81

## 바뀐 점
- **긴급 수정 — 문서뷰·아웃라이너·PDF 편집·메뉴 표시 방식(Dock) 오류**: v2.2.76~v2.2.79에서 이 화면들을 열면 "앱 연결을 기다리고 있습니다" 오류가 나며 작동하지 않던 문제를 고쳤습니다. 화면이 부르는 기능 8개가 실제 앱 연결 부분에 빠져 있었습니다. 앞으로 화면이 부르는 모든 기능 이름이 앱 연결에 있는지 시험이 확인합니다.
- **퀵몽땅검색 화면 전면 정리**: 본문·위계·파일명 세 가지 검색을 하나의 통합 검색으로 합쳤습니다(탭 줄 삭제). 기간은 전체·오늘·7일간·30일간·올해로 고르며 '직접'을 없앴고, 고른 기간이 검색창에 `after:…` 같은 글자로 나타나거나 최근 검색에 쌓이지 않습니다. 오른쪽 위 '통계'·'설정' 버튼이 눌리지 않던 문제, 옵션 줄·팝업·요약 줄·결과 카드의 글자 겹침, 사이드바·바둑판 보기·통계 화면의 어긋남을 고쳤습니다. 검색 서비스가 꺼져 있을 때 "(os error 2)" 대신 알아볼 수 있는 안내가 나오고, 하단 상태줄은 한국어("문서 7건 · 폴더 3개")로 바뀌었으며 잘못 고정돼 있던 버전 표시를 없앴습니다. 결과가 선택된 상태에서 이벤트가 오면 창이 갑자기 닫히던 문제도 고쳤습니다.
- **퀵가상폴더 화면 전면 정리**: 도구 막대·탭·영역 분할선·목록·상태줄의 그리기와 클릭이 어긋나던 곳을 고쳤습니다. 끌어놓기·복제로 만든 가상 항목이 화면에 나타나지 않던 문제를 고쳐 영역마다 `[가상]` 줄로 보이고 선택·이동·열기가 됩니다. 활성 영역과 놓을 영역 표시가 Windows 11에서 보이지 않던 것도 고쳤습니다. 창 최소 크기는 420×400으로 올렸습니다.
- **몽땅클립보드 켜기**: [몽땅클립보드 켜기]를 누르면 상주 프로그램이 뜰 때까지 최대 10초 기다린 뒤 설정 화면으로 자동 전환합니다. 켜는 동안 진행 표시가 나오고 단추는 잠깁니다.
- **개발자 모드 '검색 벤치마크'(새 메뉴)**: Everything과 몽땅검색의 검색 속도와 리소스 사용(메모리·CPU·디스크)을 비교 측정하고 결과를 파일로 저장합니다. 개발자 모드에서만 보입니다. Everything이 서비스로만 실행 중이면 Everything 앱(트레이)을 실행하거나 HTTP 서버를 켜야 측정할 수 있습니다.
- **하단 Dock(시험판)**: 아이콘을 직접 그리고 이름·방향키 선택·고대비 색을 지원합니다. 설정에서 사이드바와 Dock 중 고를 수 있습니다.

## 알려진 문제
- 하단 Dock은 시험판입니다. 모든 메뉴 창이 Dock에서 바로 열리지는 않습니다.
- 퀵몽땅검색·퀵가상폴더의 화면 수정은 시험과 화면 캡처로 확인했으며 실제 마우스·모니터 배율(100~200%)에서의 확인은 설치본에서 해야 합니다.
- 퀵몽땅검색 설정의 '기본 검색 모드(키워드/파일명)' 항목은 통합 검색에서 의미가 없으며 다음 버전에서 정리합니다.

## 재연 시험
- 릴리스 직전에 실제 설치본에서 시험하고 채울 항목입니다(초안 단계에서는 미실행).
