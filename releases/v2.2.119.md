# v2.2.119

## 바뀐 점
- **퀵몽땅검색 파일명 검색이 서비스 없이도 동작**: 색인 프로그램(kfind)이 시작하자마자 바탕 화면·문서·다운로드(OneDrive로 옮겨진 폴더 포함)의 파일명 색인을 스스로 만듭니다. 전에는 색인 서비스를 설치하지 않으면 "파일명 색인을 준비하는 중입니다(names index unavailable (empty))"가 계속 떴습니다. 색인 상태 안내도 만드는 중·아직 없음·실패로 나눠 알려 줍니다.
- **설정 > 전체 드라이브 색인**: 관리자 승인(UAC) 한 번으로 색인 서비스를 켜고 끌 수 있습니다. 켜면 모든 드라이브의 파일·폴더 이름을 퀵몽땅검색에서 바로 찾습니다. 설치할 때 사용자 모드 색인 프로그램을 먼저 끝내 같은 파이프 이름이 겹치지 않게 했습니다.
- **몽땅검색 색인 수동 관리**: 앱 몽땅검색의 본문·위계검색 줄에 [색인 초기화]가 생겼습니다(저장된 색인을 지우고 처음부터 다시 만듭니다, 원본 파일은 건드리지 않음). 퀵몽땅검색 설정 > 정보에 '파일명 색인 지금 다시 만들기'가 생겼습니다.
- **몽땅검색에서 폴더 이름도 검색**: 앱 몽땅검색은 색인된 문서가 든 폴더를 이름으로 찾아 결과 맨 앞에 보여 주고, 퀵몽땅검색은 폴더 결과에 '폴더' 꼬리표를 붙입니다.
- **몽땅검색 첫 실행이 느리던 문제와 `not_connected`**: 시작 때의 색인 점검을 뒤로 돌리고 서비스가 두 번 만들어지던 경우를 막았으며, 새 검색 엔진에 못 닿으면 1분마다 다시 시도합니다. 상태 안내는 쉬운 말로 바꿨습니다.
- **스캔 PDF 변환**: 글자가 그림으로만 든 PDF를 MD·TXT·DOCX·EPUB·HTML·HWPX로 바꿀 때 내장 OCR을 자동으로 쓰고, OCR이 없거나 글자를 못 읽으면 빈 파일을 만들지 않고 이유를 알립니다.
- 문서 선택·파일변환 화면에서 「표 칸 그림을 배경으로」를 뺐습니다.

## 알려진 문제
- v2.2.86~v2.2.118 노트의 '알려진 문제'가 남아 있습니다.
- 이미 색인 서비스(`HwpAutoDocFit.Index`)를 설치해 둔 PC는 서비스가 계속 옛 `kfind.exe`를 실행합니다. 새 색인 프로그램을 쓰려면 설정 > 전체 드라이브 색인에서 끄고 다시 켜세요.
- 서비스를 켜기 전에는 바탕 화면·문서·다운로드만 파일명 검색이 됩니다(전체 드라이브는 서비스 필요).
- 앱 몽땅검색 결과를 더블클릭하거나 [문서 열기]를 눌러도 열리지 않는 문제, 폴더 결과 열기는 아직 고치지 못했습니다. 퀵몽땅검색에서 본문 색인 시작·초기화는 없습니다.
- 퀵몽땅검색 창에 다크 테마가 적용되지 않는 문제, PDF 편집 끌어 놓기·파일 선택 문제는 이번에도 남아 있습니다.
- 앱 몽땅검색의 등록 폴더는 퀵몽땅검색 파일명 색인에 아직 합쳐지지 않습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다. Windows에서 UAC 서비스 설치·제거, 색인 자동 생성, 폴더 검색은 확인하지 못했습니다.
