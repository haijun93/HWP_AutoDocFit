# v2.2.92

## 바뀐 점
- **퀵몽땅검색 `;` 묶음별 강조**: 검색어를 `;`로 나누면 묶음마다 번호 칩과 서로 다른 색이 붙고, 결과 발췌에서 묶음별로 색이 칠해지며 일치 배지가 표시됩니다(최대 8묶음, 밝은·어두운 테마, 100·125·150% 배율에서 확인). 묶음을 나누는 규칙은 검색 서비스와 같은 공용 함수를 씁니다(따옴표·`ext:` 안의 `;`는 나누지 않음).
- **PDF 판정 엔진 Rust 이식(내부, 아직 앱에 연결되지 않음)**: PDF가 손상·암호·권한 제한·서명 문서인지 가리는 판정과 메모리에서 연속 편집(회전·삭제·순서·합치기)하는 부품을 Rust로 만들었습니다. 합성 PDF 36건에서 기존 Python 판정과 모두 일치함을 확인했습니다. 실제 업무 문서로는 아직 대조하지 못했습니다.
- 내부 문서: PDF 쪽 썸네일 Windows 내장 엔진 실측(속도가 기존보다 느려 채택 보류), 퀵몽땅검색 첫 입력 지연 측정(프리워밍 효과 없음).

## 알려진 문제
- v2.2.86~v2.2.91 노트의 '알려진 문제'가 그대로 남아 있습니다.
- 퀵몽땅검색 결과 그리기 1회가 부하 시 약 35ms로 16ms 목표에는 못 미칩니다.
- PDF 판정 Rust 이식은 아직 앱 동작에 쓰이지 않아 사용자에게 보이는 변화가 없습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
