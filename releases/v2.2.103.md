# v2.2.103

## 바뀐 점
- **사진뷰·문서뷰 다중 선택**: Shift+클릭(범위), Ctrl+클릭(추가·해제), Ctrl+A(전체), Esc(해제).
- **파일 작업**: 복사(Ctrl+C), 폴더로 복사, 폴더 이동, 삭제(Delete), 파일명 변경(F2). 삭제는 휴지통으로만 보내며 확인창이 뜹니다. 이동·복사는 덮어쓰지 않고 ` (2)` 를 붙입니다. 사진뷰에서 삭제한 사진의 태그·즐겨찾기 기록은 지워집니다(휴지통에서 되살려도 돌아오지 않음).
- **오른쪽 클릭 메뉴**: 문서뷰는 문서편집·가상 폴더·업무자료함·파일 변환·PDF 편집, 사진뷰는 사진 편집(사본)·파일 변환·가상 폴더·첨부용 사본·사진대지로 바로 보냅니다.
- 고침: 사진뷰의 제외 폴더·썸네일 크기 설정이 저장되지 않던 문제.
- 내부(기본 꺼짐): 단축키 검색창 통합 검색(`unified_search`: 파일명 → 위계 → 본문), 업무 연보 열지도·타임라인 표와 통계 XLSX 생성기(앱 미연결).

## 알려진 문제
- v2.2.86~v2.2.102 노트의 '알려진 문제'가 남아 있습니다(사진뷰 크게 보기 순번 문제는 고쳤습니다).
- xls·ppt·pptx·hml 은 문서편집·파일 변환 메뉴가 비활성입니다. 파일 변환을 새 창 방식으로 쓰면 메뉴에서 파일을 넘기지 못합니다.
- 설치본에서의 클릭·단축키·오른쪽 메뉴, 탐색기 붙여넣기는 확인하지 못했습니다. 네이티브 문서뷰·사진뷰 창에는 다중 선택·파일 작업·오른쪽 메뉴가 없습니다.
- 통합 검색의 첫 화면 16ms 목표는 미달입니다. 업무 연보는 한/글 2020 에서 확인하지 못했습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
