# v2.2.91

## 바뀐 점
- **몽땅검색 `;` 다중 묶음 교집합(파일명)**: 검색어를 `;`로 나누면 각 묶음을 모두 만족하는 파일만 찾습니다(예: `보고서; 예산`). 묶음은 최대 8개이고, 한 묶음일 때의 결과와 속도는 이전과 같습니다. 따옴표 안의 `;`와 `ext:hwp;pdf`는 나누지 않습니다. 이전에 `예산;공사`가 한 낱말로 처리되던 동작은 두 묶음 교집합으로 바뀝니다.
- **파일변환 Win32 창 2~4단계(선택형, 기본은 기존 화면)**: 파일별 백그라운드 변환과 진행·완료·실패·취소 표시, 결과 파일·폴더 열기, 실패 사유 표시, 두 번째 실행 시 기존 창으로 파일 전달, 'PDF 하나로 합치기'의 순서 변경(Alt+↑/↓).
- **파일명 일괄변경 Win32 창 2~4단계(선택형, 기본은 기존 화면)**: 파일 드롭·열기, 접두사·접미사·순번·찾아 바꾸기(정규식 선택) 규칙과 충돌 미리보기, **실제 이름 변경과 직전 작업 되돌리기**(저널 기록, 적용 중 취소, 다크 모드). 설정 `rename_ui`를 `native`로 바꿀 때만 사용됩니다.
- 내부: 문서 상태 메모·주간 진행 요약 갱신.

## 알려진 문제
- v2.2.86~v2.2.90 노트의 '알려진 문제'가 그대로 남아 있습니다.
- 새 파일명 변경 창의 한글 IME 직접 입력, 적용 확인 대화상자, 마우스 올림·키보드 포커스 모양은 실제 PC에서 확인하지 못했습니다. **사용자 폴더에서는 먼저 사본으로 시험해 주세요.**
- 파일변환 창에서 PDF 압축 옵션은 아직 연결되지 않았습니다(앱 설정 값 사용).
- 여러 묶음 검색은 입력을 이어 쓸 때 앞 결과 좁히기 캐시를 쓰지 않습니다.

## 재연 시험
- 설치본 시험은 하지 않았습니다(사용자 지시).
