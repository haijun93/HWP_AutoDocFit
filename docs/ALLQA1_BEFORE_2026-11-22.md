# ALLQA1 개선 전 기준선 (BEFORE)

작성일: 2026-11-22 · 대상 코드: `github/main` 기준 · 앱 버전 `2.2.92` · 작업 방식 `all` · 기준선 1회 실행

## 측정 개요

- 세트 6개 중 5개 정상 완료, 1개 오류. 전체 경과시간 합계 638.666초, COM 호출 154,212회, COM 계측 시간 합계 427.183초.
- 필수 COM 잠금 상태에서 순차 실행했다. 측정 중 다른 시험·빌드는 실행하지 않았고, 종료 후 잠금이 해제됐다.
- HWPX 결과, COM 계측 JSON, 단계 로그, 문서별 JSON은 사용자 지정 외부 폴더에 저장했다. 처리 문서 사본과 결과 파일은 저장소에 커밋하지 않는다.
- 첫 호출은 저장소 import 경로 오류로 COM 잠금 취득 전 종료됐다. 경로를 보완한 후 실제 측정은 한 번만 했다.
- 문서별 전체 시간은 스모크 보고서의 경과시간이며 단계·COM 시간은 `com_perf` 계측값이다. 전후 비교는 같은 계측 방식을 사용해야 한다.

## 결함 및 측정 범위의 공백

- `txt_short`, `txt_long`: 원본 TXT와 결과 HWPX의 공백 제외 텍스트가 일치하지 않았다. false 판정을 그대로 기록했다.
- `hwp_reference`: 기존 스모크 도구가 HWP 입력을 UTF-8 텍스트로 읽어 원문 대조가 false였다. 출력 문단 수도 0으로 기록돼 유효한 본문 보존 검수가 되지 않았다.
- `hwpx_table`: 한/글이 픽스처를 열지 못해 오류 1건, 종료 코드 1, 저장 결과 없음.
- 관측된 페이지 크기는 1쪽 4건, 2쪽 1건이다. 5쪽 및 10쪽 이상 문서는 이번 세트에 없어 해당 크기 기준선은 미측정이다.
- 요청 배경의 특정 기능시연 TXT를 확보하지 못해 짧은 연속문장 및 AI 답변 픽스처로 대체했다. 해당 대표 시연 문서의 성능 기준선은 미측정이다.
- 사용자 업무 문서는 사용하지 않았다. 처리 전후 원본 픽스처와 처리 입력 사본 해시는 모두 불변이었다.

## 전후 비교 해석

- 이번 BEFORE 세트는 6개 픽스처로 구성됐고, `COM_기준선_v2.2.58_2026-11-12.md`는 별도의 기능시연 TXT 1개다. 두 세트의 322.8초·144,274회와 이번 수치를 직접 성능 증감으로 비교할 수 없다.
- 개선 후에는 같은 세트·옵션·COM 계측 조건으로 측정하고 `scripts/allqa_compare.py`에서 단계별 시간 증감률, 총 시간, COM 호출 수, 문단 차이 및 텍스트·서식 XML 해시를 대조한다.
- 이 문서는 개선 전 결과만 기록한다. 전후 결과 동일성은 아직 판정하지 않았다.
