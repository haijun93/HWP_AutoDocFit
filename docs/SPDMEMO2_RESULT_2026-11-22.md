## 정규화 규칙과 근거

1. `Contents/header.xml`의 `paraProperties/paraPr`에서 정의 자체의 `id`를 빼 속성 트리를 만들고, 해당 정의 목록 안에서만 정렬한다.
2. 구역 XML의 `paraPrIDRef`는 숫자 대신 연결된 정의 트리로 치환한다. ID·정의 순서 재배치는 흡수하지만 여백·들여쓰기·줄간격 값 변경은 해시에 남긴다.
3. 표 `tbl/@id`는 패키지의 모든 XML에서 참조되지 않는 경우만 제외한다. 표의 속성·자식·요소 순서는 그대로 비교한다.
4. 모든 `Contents/*.xml`의 나머지 구조·속성을 정규화 서식 해시에 포함한다. `<t>` 본문은 별도 텍스트 해시로 비교하고 원시 서식 해시도 진단용으로 남긴다.

BEFORE와 verify의 문단 모양 정의 34개는 `id`를 제외하면 동일한 다중집합이었다. `paraPrIDRef`는 재배치된 정의를 가리켰고 문단 비교는 0건이었다. 변한 표 ID는 XML 전체에서 참조되지 않았으며 표 속성은 그대로였다. 합성 HWPX 시험에서 ID/순서만 바꾸면 해시가 같고 문단 여백 또는 표 너비를 바꾸면 해시가 달라짐을 확인했다.
