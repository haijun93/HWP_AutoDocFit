# OUTLINEUI2 구현 기준

- 결과: `docs/OUTLINEUI2_RESULT_2026-11-26.md`. 대상은 `outliner_core`, `outliner_win` 두 크레이트. 기능 브랜치 로컬 커밋까지만 진행한다.
- 선행: OUTLINEUI1 커밋 `bfe01e2d`와 결과 문서의 시험 통과를 확인하고 fast-forward 병합했다. 구현 전 두 크레이트 전체 시험을 재실행한다. 실패하면 중단한다.
- 확인 근거: [Logseq 0.10.9 block.cljs](https://github.com/logseq/logseq/blob/0.10.9/src/main/frontend/components/block.cljs#L1560-L1668)의 불릿 클릭·Shift+클릭·드래그와 별도 접기 화살표. 동작만 참고하며 코드·CSS·아이콘 등 AGPL 자산은 복사하지 않는다.
- 불릿은 모든 블록에 표시한다. 기존 EDIT·TODO 좌표를 유지하며 왼쪽 여백 안에 삼각형·불릿을 따로 둔다. 안내선과 입력 판정도 같은 치수 모델을 사용한다.
- 줌은 문서 전체를 보관한 채 선택 블록과 하위만 표시하는 메모리 상태다. 상위 경로는 페이지·조상으로 돌아가며 뒤로는 직전 줌으로 돌아간다. 파일 형식과 저장 내용에 줌 상태를 넣지 않는다.
- 이동은 `Before / After / Child` 세 위치다. 같은 문서 안에서 하위·속성·상태를 동반한다. 자기 자신·하위 대상·보존 문법 경계를 거부하며 실패 시 입력 문서를 그대로 둔다. 한 번 놓기는 실행 취소 한 단계다.

| 상태 | 전이 | 금지·취소 |
|---|---|---|
| 전체 / 블록 줌 | 불릿 클릭·상위 경로·뒤로 | 없는 블록 진입 거부, 문서 재파싱(실행 취소/다시 실행) 때 순번 오지정 방지를 위해 전체로 복귀 |
| 포인터 Idle / Armed / Dragging | 불릿 누름 → 시스템 이동 문턱 초과 → 놓기 | Esc·캡처 상실·창 밖 놓기는 변경 없이 Idle |
| 드롭 없음 / 앞 / 뒤 / 자식 | 포인터의 행 내 세로 구간·들여쓰기 위치로 결정 | 자기 하위·없는 대상은 드롭 불가 표시 |
| 편집 / 조합 / 확정 | 기존 Editor 확정 경로 이후 탐색·이동 | 조합 확정이 끝나지 않으면 이동하지 않음 |

- 오른쪽 메뉴는 Win32 네이티브 메뉴로 줌·우측 카드·접기/펼치기·하위 포함 복사/삭제·실행 취소를 제공한다. 지원하지 않는 UUID 생성/참조 메뉴는 추가하지 않는다.
- 시험: 두 변경 크레이트 cargo test 전체, 관련 Python 시험. 합성 Markdown만 사용하며 임시 자료는 작업 폴더 내부로 제한한다. 전체 Python·Flutter는 PM 릴리스 검증에 남긴다. 속도·메모리 개선 수치는 측정 없이 주장하지 않는다.
- 설치본·서비스·자동 실행·사용자 설정·기본 실행 전환·Flutter·COM·XML 파서는 변경하지 않는다. PC 전용 빌드 경로는 프로세스 환경변수만 사용한다. UTF-8·CRLF를 보존한다.
