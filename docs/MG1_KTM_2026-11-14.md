# MG1 몽땅검색 단축키 앱(ktm) 1차 기록 (2026-11-14)

브랜치 `feature/mongttang-search-app`. Codex(상태 기계 `tm_state`, d8b03d03) → Gemini(창·백엔드·설치 등, 미커밋) → Claude(검토·수정·측정·커밋).

## 구성
- `ktm/src/tm_state.rs` 순수 상태 기계(숨김·표시·입력 중·검색 중·결과·오류)
- `window.rs` Win32 창(마우스 옆, Per-Monitor DPI v2, IME 조합 중 키 무시, GDI 이중 버퍼, 다크·라이트·고대비, Ctrl+L 테마)
- `backend.rs` 색인 mmap 직접 읽기(기본) / 서비스 파이프(`--backend pipe`, 2글자·본문만)
- `kfind/core` `Index::search_character` 추가: Enter로 보낸 1글자 검색(비교 글 직접 훑기, 취소·범위 존중)
- `install.rs` `--install`(로그인 자동 실행 **기본 켬**, `--no-autostart`로 끔) · `--uninstall` · `--autostart-on/off`
- `open.rs` 로컬 절대 경로만, 실행 파일·바로가기 차단
- 라이선스: `ktm/LICENSE` PolyForm Strict 1.0.0, `Cargo.toml`의 `license-file`

## 남은 단계
1. 첫 표시 지연: 시작할 때 창을 한 번 그려 두기(숨김 상태 사전 그리기)·색인 미리 열기
2. 위계 탭 1초: `top:0`으로 전체 결과를 모은 뒤 정렬 → kfind에 위계 우선 상위 N 질의 필요
3. 원문 문장 없음: 현재 색인에 원문 문장이 없어 "일치 문장 강조"는 위치만 표시(엔진 쪽 원문 보관 결정 필요)
4. 파일명 탭: FN1(feature/kfind-names) 들어오면 연결
5. mmap↔파이프 비교(`examples/compare.rs`)는 실제 서비스 기동 상태에서 1회 더
