# 퀵몽땅검색 — Docufinder AI 제외 기능 대조표

작성일: 2026-11-15 · 카드: QMS-PARITY · 범위: 조사와 계획만(코드 수정 없음)

## 근거와 판정 기준

- Docufinder 기능의 근거는 저장소 안의 `docs/DFB2_COMPARE_2026-11-12.md`, 동반 raw JSON, 그리고 이미 작성된 `docs/TM_SEARCH_DESIGN.md`만 사용했다. raw JSON과 DFB2는 동일 corpus 검색 성능·검색어 동작 비교이며 Docufinder 기능 명세 전체가 아니다. TM_SEARCH_DESIGN은 Docufinder 벤치마킹을 위해 저장소에서 이미 정한 검색·편의 기능 목록이다.
- 그래서 아래 목록은 **저장소 문서로 확인되는 AI 제외 기능**이며 Docufinder 제품의 완전한 기능 목록이라고 단정하지 않는다. DFB2에서 실제 관찰된 내용(파일명+본문 결과, 화면 최대 50건, 입력 중 자동 갱신, 앱 표시 시간)은 참고 사실로 한정한다. DFB2 본문 검색 비교는 같은 동작을 확인한 것이 아니므로 구현 사양으로 확대하지 않았다.
- 현재 지원은 코드에서 사용자 경로까지 이어지는 것을 확인한 경우만 `지원`, 엔진 API/기반만 있는 경우 `부분`, 조사한 코드에 없는 경우 `미지원(검색 범위 기준)`, 원천 근거에 기능 자체가 기술되지 않은 경우 `미확인`으로 적었다. 미확인은 누락 판정과 다르다.
- 속도 영향은 정량 측정값이 아니라 검색 hot path에 대한 예상이다. 기준 목표는 TODO 원문에 적힌 입력→첫 표시 16ms·상주 증가 2MB 이하. DFB2의 Rust 엔진 계산은 상위 20건 0.02~1.36ms, 전체 검색 최악 2.74ms였지만 화면 왕복을 포함하지 않아 그 목표의 달성 증거로 쓰지 않는다.

## 구현 카드 묶음(의존 순서)

1. **QMS-QUERY** — 질의 파서/엔진 연결: 정확 구문, 제외어, `ext:`, `path:`, `after:`·`before:`. 선행: 연산자 우선순위·따옴표/이스케이프 문법 명세와 기능별 결과 회귀 기준 확정. 위치: `kfind/core/src/query.rs`, `index.rs`, `ktm/src/backend.rs`. 난이도 중. 색인 후보 bitmap을 먼저 좁혀 입력→첫 표시 목표 보호.
2. **QMS-SCOPE** — 임의 폴더·확장자·날짜 범위 UI와 통합 검색 범위. 선행: QMS-QUERY의 파싱/범위 모델. 위치: `ktm/src/tm_state.rs`, `window.rs`, `backend.rs`; `kfind/core/src/index.rs`. 난이도 중. 선택 범위가 작을수록 검색 계산 감소.
3. **QMS-RESULTS** — 일치 문장 옆 위치 배지(쪽·시트·행 등 kfind 위치 메타가 있는 것만, 없으면 생략), 결과 선택 시 미리보기 줄(선택 행의 일치 문단 전체 3줄), 본문 탭 결과 정렬 순환(관련도·수정일·이름, Ctrl+S 기존 방식 확장). 검색 처리 로직은 최소 변경, window.rs 그리기 중심. 한글 조합 보호(사용자 입력 경로 SetWindowText 금지). 위치: `ktm/src/backend.rs`, `paragraphs.rs`, `window.rs`. 난이도 중. 상위 결과만 채우고 상세 미리보기는 선택 행 대상 렌더링.
4. **QMS-HISTORY** — 최근 검색·즐겨찾기 검색 저장/불러오기. 선행: 연산자·범위가 포함된 검색 상태 DTO 확정(QMS-QUERY/QMS-SCOPE). 위치: `ktm/src/settings.rs`, `tm_state.rs`, `window.rs`. 난이도 낮음~중. 검색 hot path 추가 비용 없음.
5. **QMS-EXPORT** — 현재 탭 검색 결과 CSV/TSV 내보내기(기존 카드 5번 중 내보내기 선행 분리). 화면 상한과 무관하게 최대 1,000건, Ctrl+E로 형식(CSV/TSV) 선택, 사용자 문서 폴더의 '퀵몽땅검색_결과_날짜시각.csv' 저장 후 폴더 열기. 열: 번호·파일명·경로·형식·수정일·일치 문장(본문 탭) 또는 크기(파일명 탭). 쉼표·따옴표·줄바꿈 이스케이프 정확히, UTF-8 BOM(Excel 호환), 외부 전송 없음. 결과 DTO·직렬화는 `ktm/src/export.rs`로 분리하고 `window.rs` 변경 최소화. 검색칸 글 다시쓰기 금지(한글 조합 보호).
5-1. **QMS-FORMATS-METADATA** — 포맷별 위치 완전성(PDF 쪽·스프레드시트 시트/행 배지·암호 문서 건너뜀 상태) 연계. 선행: QMS-RESULTS의 안정된 결과 DTO 및 위치 메타. 위치: 색인 추출 파이프라인, `ktm/src/backend.rs`. 난이도 중~높음.

> 이 문서는 대조표만 제시한다. 구현, 측정, 시험 실행, 브랜치·버전 변경은 수행하지 않았다.
