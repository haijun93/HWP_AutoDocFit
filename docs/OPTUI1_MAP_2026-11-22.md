기준: github/main(PROG1 병합 뒤) `5394a61c`. 이 문서는 **변경 전** 상태를 기록한다. 기능·기본값·저장 형식은 바꾸지 않았다.

## 1. 내부 작업 유형(mode)과 카드 3장의 대응

| 화면 카드 | 내부 mode | 세부 작업 수(`stages_for_mode`) | 비고 |
|---|---|---|---|
| 자간 정리 | `spacing` | 11 | `page_fit`·`page_group`은 기본 꺼짐 |
| 서식 통일 | `unify` | 7 | `style_unify`·`unify_spacing`·`table_unify`·`table_style`·`page_layout_keep` 기본 켜짐 |
| 한 번에 적용 | `all` (자간 조정 포함) / `format` (자간 조정 제외) | 28 / 21 | 카드는 1장이고 `include_spacing`(설정 `all_include_spacing`) 값으로 내부 mode가 `all`↔`format` 전환. 화면은 `cardMode`(format→all)로 같은 카드에 표시 |
| (카드 없음) | `file_format` | - | 파일 변환(결과 형식 고르기). 세부 작업·옵션 없음 |
| (카드 없음) | `pagefit` | - | 예전 '페이지 맞춤' 카드. 내부는 `spacing`에서 자간만 끄고 쪽 맞춤만 켠 흐름(`_page_fit_card`) |

`set_mode`가 `format`/`all`을 받으면 `include_spacing_var`로 내부 mode를 정하고, `pagefit`은 `spacing`으로 바꾼다.

## 2. 한 번에 적용 옵션 5개(+@)의 위치

| 옵션(화면 문구) | 설정 키 | 변경 명령 | 카드 화면 | 설정 화면 | 연동되는 세부 작업(`CARD_OPTION_STAGES`) |
|---|---|---|---|---|---|
| 자간 조정 포함 | `all_include_spacing` | `set_include_spacing` | 카드 | 전체 설정 '한 번에 적용: 자간 포함' | `all` 의 자간 7작업(`reset_spacing`·`body_spacing`·`short_line`·`control_spacing`·`control_short_line`·`word_check`·`control_word_check`). 하나라도 켜져 있으면 켜짐 |
| 표 제외 | `all_exclude_tables` | `set_exclude_tables` | 카드 | '한 번에 적용: 표 제외' | `TABLE_STAGE_KEYS` 9작업(`text_table_convert`·`table_style`·`table_width`·`precise_table`·`table_format`·`table_unify`·`control_spacing`·`control_short_line`·`control_word_check`). 모두 꺼졌을 때 켜짐 |

| 줄 간격 적용 제외 | `all_exclude_linespacing` | `set_card_option` | 카드 | '한 번에 적용: 줄 간격 적용 제외' | 연동 세부 작업 없음(실행 때 줄 간격 처리만 건너뜀) |
| 표 셀 그림을 배경으로 변경 | `all_cell_image_to_bg` | `set_card_option` | 카드 | '한 번에 적용: 표 셀 내 그림을 배경으로 변경' | `cell_image_to_bg` 1작업(기본 꺼짐, `DEFAULT_OFF`) |

같은 값을 바꾸는 세 곳: ① 카드의 스위치 ② 설정 화면(전체 설정·Win32 설정창)의 `all_*` 항목 ③ 세부 작업 목록의 스위치(관련 작업).

## 3. 연동 방식(단일 원천)

* 값의 원천은 앱(Tk) 화면 변수(`include_spacing_var`·`exclude_tables_var`·`all_exclude_pagefit_var` …)다. 값이 바뀌면 `docfit_ui/legacy.py`의 변수 감시가 두 방향으로 동기화한다.
  * 옵션 → 세부 작업: `_카드옵션_세부작업_반영` (옵션을 바꾸면 관련 작업을 모두 켜고 끔, 같은 카드의 다른 구성 all·format에도 적용)
  * 세부 작업 → 옵션: `_세부작업_옵션_맞춤` (`card_option_from_stages`; '제외' 옵션은 관련 작업이 모두 꺼지면 켜짐, '포함' 옵션은 하나라도 켜지면 켜짐)
* Flutter 화면은 값을 따로 들고 있지 않고 `get_state()` 응답(`card_options`·`include_spacing`·`exclude_tables`·`table_spacing`·`stages`)만 그린다. 따라서 카드·세부 작업은 같은 응답에서 그려져 어긋날 수 없다.
* 주의: `include_spacing`·`exclude_tables`는 `card_options`(`all_include_spacing`·`all_exclude_tables`)와 같은 값을 두 이름으로 내려 준다. 카드 화면은 두 이름을 섞어 읽는다(`includeSpacing`·`excludeTables` 게터 / `cardOption()`).
* 자간 정리 카드의 '표 제외'는 설정 `table_spacing`의 **반대 값**이다(설정 화면 문구는 '표 안 자간 정리').

## 4. 세부 작업 목록(28개, `all`) 묶음

Flutter `stage_board.dart`의 분류(`stageGroups`)를 쓴다.

| 묶음 제목 | 작업 키 |
|---|---|
| 문서 서식 | `abbreviation`·`standard_format`·`text_table_convert`·`pre_format`·`attachment_font`·`asterisk_superscript`·`style_unify`·`unify_full_format` |
| 문장·기호 (내어쓰기 포함) | `normalize_space`·`punctuation_space`·`parenthesis`·`hanging_indent`·`supplement_indent`·`star_align` |
| 표 | `table_style`·`table_width`·`precise_table`·`table_format`·`table_unify`·`single_cell_spacing` |
| 자간·줄 끝 | `reset_spacing`·`body_spacing`·`short_line`·`control_spacing`·`control_short_line`·`word_check`·`control_word_check`·`unify_spacing` |
| 쪽 배치 | `page_fit`·`page_group`·`page_layout_keep` |

(`cell_image_to_bg`는 어느 묶음에도 없어 '문서 서식'으로 떨어진다 — `stageGroupOf`의 기본값.) 카드에는 28개 중 `all`에 해당하는 것만 나오며, 서식 통일·자간 정리 카드는 7·11개다.

## 5. 이번 정리의 방향(화면 구성만)

1. 카드: 핵심 옵션 2개만 바로 보이고 나머지는 '고급 설정' 접기(켜 둔 옵션 개수를 접힌 제목에 표시, 펼침 상태는 화면이 떠 있는 동안 기억).
   * 한 번에 적용: 핵심 = 자간 조정 포함·표 제외 / 고급 = 표 셀 그림을 배경으로 변경·줄 간격 적용 제외·페이지 맞춤 제외
   * 자간 정리: 핵심 = 자간 정리·페이지 맞춤 제외 / 고급 = 표 셀 그림을 배경으로 변경·기존 자간 초기화 제외·표 제외
   * 서식 통일: 핵심 = 표 제외·자간 정리 제외 / 고급 = 페이지 맞춤 제외·원본 쪽 구성 유지·전체 서식 맞추기
2. 세부 작업: 묶음 제목별 접힘 + 묶음 전체 켜기/끄기 + 'N개 중 M개 사용' 요약.
3. 문구는 바꾸지 않고, 혼동되기 쉬운 두 곳(`표 제외`가 카드와 세부 작업에서 같이 바뀐다 / `고급 설정`에 든 옵션이 켜져 있음)에만 보조 설명 문장을 더한다.
