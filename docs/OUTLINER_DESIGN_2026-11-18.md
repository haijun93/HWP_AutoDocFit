# OUTLINER1 설계 — Logseq식 아웃라이너 엔진

작성일: 2026-11-18. 구현 범위는 Rust 엔진과 JSON CLI까지다. 사이드메뉴와 Flutter 화면은 OUTLINER2에서 다룬다.

## 벤치마킹 범위

블록 중심 문서와 마크다운 저장, 페이지/블록 링크, 역링크, 일일 페이지, 태그·속성, TODO/DONE, 빠른 전문 검색을 Logseq에서 참고한다. AI 기능, 플러그인, 그래프 화면, 동기화, 협업, 브라우저 기반 UI는 제외한다.

포함하는 블록 작업은 불릿 트리와 들여쓰기/내어쓰기, 접기/펼치기 상태, 위/아래 이동, 분할/병합, 삽입/삭제다. 편집 API는 안정적인 블록 ID를 사용하고, 텍스트 파일 자체에는 별도 ID 문법을 강제로 넣지 않는다.

## 저장 및 왕복 보존

사용자 폴더 아래 일지와 페이지별 `.md` 파일을 저장한다. 기본 데이터 폴더는 OS 사용자 데이터 경로의 `DocFit/Outliner` 하위이며, CLI에는 명시적인 파일 경로를 전달한다. 문서 파일은 UTF-8 마크다운이고 목록은 `- `와 들여쓰기를 사용해 Logseq와 호환한다.

파서는 각 입력 줄의 원문을 보존하고, 인식 가능한 불릿만 편집 가능한 블록으로 만든다. 코드 울타리 내부, 일반 문단, 미지원 구문, 공백·탭 혼합, 줄바꿈 형식은 불투명 원문 노드로 보존한다. 편집하지 않은 문서는 바이트 단위로 동일하게 직렬화한다. 편집 시 블록 줄만 공백 들여쓰기로 정규화하며, 보존 노드는 그대로 출력한다. 들여쓰기 수준은 입력 접두 공백 문자 수를 사용하며 탭은 시각 폭 4칸으로 환산한다.

저장은 같은 디렉터리의 임시 파일에 전체 내용을 쓰고 동기화한 다음 원자적 교체를 시도한다. 교체 실패 시 기존 파일을 유지하고 임시 파일을 정리한다. 한 파일을 동시에 편집하는 다중 프로세스 조정은 엔진 1단계 범위 밖이며 이후 UI 서비스에서 잠금 정책을 제공한다.

## 엔진 구조 및 API

`outliner_core/`는 라이브러리와 `outliner.exe` 바이너리를 제공한다. 표준 입력의 한 줄 JSON 요청마다 표준 출력 한 줄 JSON 응답을 쓴다. 요청은 `{"id":"...","op":"parse|serialize|edit|search|backlinks|daily_page","document":"...","args":{...}}` 형태다. 성공은 `{"id":"...","ok":true,"result":...}`, 오류는 `{"id":"...","ok":false,"error":{"code":"...","message":"..."}}`다. 프로세스는 여러 요청을 순서대로 처리한다. CLI 경로 I/O 오류와 JSON 형식 오류는 명시적인 오류 응답이 되며 stdout에 진단 문구를 섞지 않는다.

라이브러리의 블록 트리는 임시 ID, 텍스트, TODO 상태, 접힘 상태, 속성, 태그, 링크, 자식 목록을 가진다. 접힘 상태는 세션 메모리 전용이며 Markdown에 기록하지 않는다. 페이지 링크는 `[[페이지]]`, 블록 참조는 `((블록ID))`를 추출한다. 역링크 색인은 메모리 내 페이지명/블록 ID → 참조 블록 ID 목록이다. 검색은 대소문자 무시 부분 일치이며 최소 2 Unicode scalar 값의 질의를 허용한다.

날짜 페이지 이름은 ISO `YYYY-MM-DD`다. `TODO`와 `DONE`은 블록 시작 표식으로 읽고 저장한다. `#태그`와 `key:: value`는 원문 텍스트를 유지하면서 메타데이터로도 추출한다.

## 자원 한도와 오류 처리

- 입력 문서: UTF-8 최대 10 MiB, 초과 시 `DOCUMENT_TOO_LARGE`.
- 블록: 한 문서 최대 100,000개, 초과 시 `TOO_MANY_BLOCKS`.
- 검색 질의: Unicode scalar 2개 이상, 짧으면 `QUERY_TOO_SHORT`.
- 잘못된 UTF-8, 구조가 깨진 JSON, 범위를 벗어난 블록 연산, 존재하지 않는 참조는 원본을 변경하지 않고 코드화된 오류를 돌려준다. 알 수 없는 마크다운 줄은 오류가 아니라 보존 대상이다.
- 외부 런타임 의존성은 serde/serde_json만 사용한다. CLI JSON 계약에 필요하며 나머지 처리는 표준 라이브러리로 수행한다.

## OUTLINER2 제안

Rust 엔진을 앱 리소스에 포함하고 Python 또는 네이티브 브리지에서 호출한다. 사용자 데이터 폴더 선택, 파일 잠금 및 동시 변경 대응, 사이드메뉴 진입, 편집기 화면, 접힘 상태 세션 관리, 키보드 접근성, 설치·CI 번들 검증을 구현한다. 기존 PDF 엔진과 같은 리소스 검색·패키징 패턴은 별도 카드에서 연결한다.
