# XMLPASS2 결과 — 자간 XML 사전 필터 그림자 계측

작성: 2026-11-24 · 기준 브랜치: `feature/XMLPASS2` · 실제 자간 건너뛰기: 없음

## 판정

**적용 후보 아님.** 문단 폭 예측과 COM 문단 위치를 연결하는 입력 경로가 완성되지 않아 ALLQA에서 예측 가능한 문단은 0개였다. 따라서 오판 0건은 정밀도 통과를 뜻하지 않으며, 정밀도는 산출할 수 없다. 건너뛸 문단과 호출 절감도 각각 0개·0회(자간 단계 호출의 0%)로, 요청한 10% 절감 기준을 충족하지 못했다. 이번 자료로 필터 안전성을 판정할 수 없다.

## 구현

- `docfit_core/spacing_prefilter.py`: HWPX 문단 요소와 명시적 쪽 기하 입력을 받는 순수 함수 `fits_one_line_for_sure(paragraph, page_geometry)`. 단일 일반 run만 평가하고, 탭·필드·표·컨트롤·복수 run·양쪽 정렬·불명 글꼴·들여쓰기·불충분한 기하 정보는 False로 닫는다. 글자 폭은 `char_width_factor`를 최소 1em으로 올리고, 글자 크기·장평·자간을 반영한 뒤 5% 폭 여유를 둔다.
- `DOCFIT_SPACING_PREFILTER_SHADOW=1`이면 자간 루프의 `hwp_run`을 관찰해 JSONL로 남긴다. 예측 근거가 연결되지 않은 경우에도 처리는 계속되며, 어떤 예측으로도 문단을 건너뛰지 않는다.
- `scripts/prefilter_report.py`: JSONL의 예측 건너뜀·오판·호출 절감·관찰 호출을 집계한다.
- `tests/test_spacing_prefilter.py`: 짧은 문단, 경계, 탭·필드·표·컨트롤, 혼합 run, 양쪽 정렬, 큰 장평·자간을 확인한다.

JSONL과 원본 측정 자료, 비교 보고서, 입력 사본은 저장소 밖 임시 작업 폴더에 두었다.

## 남은 일

실제 사전 필터 정밀도를 재려면 입력 HWPX의 run·charPr·paraPr·section 기하를 해석하고, 그 문단을 COM의 section/paragraph 위치에 안정적으로 대응시켜야 한다. 이 연결 전에는 후보가 0개이므로 shadow 수치가 적용 근거가 되지 않는다. 실제 건너뛰기는 구현하지 않았다.
