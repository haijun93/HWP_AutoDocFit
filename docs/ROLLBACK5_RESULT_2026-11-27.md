# ROLLBACK5 — 1쪽 맞춤 실패 때 바뀐 자간 원복

작성: 2026-11-27 · 브랜치: `feature/ROLLBACK5` · 로컬 커밋만, 푸시 없음.

## 확인

사실이었다. `보고서_1쪽_맞춤`의 `자간보관`은 빈 목록으로 만들어진 뒤 아무것도 담기지 않아 `자간원복`이 할 일이 없었다. 줄 수를 맞추는 `문단_줄수_원본맞춤` → `다음단어_당김_시도`가 성공한 당김의 자간은, 1쪽 맞춤이 실패·취소·예외로 끝나도 남았다.

## 수정

| 파일 | 내용 |
|---|---|
| `docfit_engine/spacing.py` | `다음단어_당김_시도`와 `단어_장평_추가축소_시도`가 자간을 처음 바꾸기 직전에, 이미 읽어 둔 글자별 원래 값을 `쪽맞춤_자간기록`에 담는다(기록이 열려 있을 때만). |
| `docfit_engine/page_fit.py` | 1쪽 맞춤의 '줄 수 맞춤' 구간에서만 기록을 연다. 맞춤이 성공하지 못하면(실패·취소·예외) 원복한다. |
| `docfit_engine/layout_restore.py` | 신규 `restore_char_spacing`: 바꾼 역순으로 다시 쓰고 글자마다 다시 읽어 7칸 자간을 확인한다. 확인하지 못하면 `fail_required_edit`(저장 차단). |

- 원래 값은 '이번 맞춤이 바꾸기 직전' 값이라 앞 단계(본문 자간·단어 분리)의 자간 조정은 유지된다.
- 자간 7칸만 쓰므로 굵게 등 다른 글자 모양은 건드리지 않는다.
- 맞춤이 성공하면(뒤의 줄간격 단계에서 성공해도) 바꾼 자간을 그대로 둔다.
- 본체 `hwp-auto-docfit.py`는 바꾸지 않았다(CRLF 유지). 이제 쓰는 곳이 없는 `문단_자간_읽기`·`문단_자간_적용`은 남겨 두었다.

## 한/글 호출 수

원래 값 보관에는 **읽기를 추가하지 않았다**(당김이 원래 하던 읽기를 재사용). 늘어나는 호출은 원복(다시 쓰기·확인 읽기)이며 성공하지 못한 경우에만 생긴다.

## 실제 한/글 전후 확인(합성 문서)

잠금 규칙에 따라 COM 잠금을 배타 생성하고 DispatchEx 새 인스턴스만 사용했으며 끝나면 종료했다. 설정 폴더는 임시 폴더로 돌렸다. 수정 전은 HEAD 사본이다. 파이프라인 전체나 EXE가 아니라 `보고서_1쪽_맞춤`(직접)과 `보고서_페이지수_맞춤_전체_적용`(진입, 원본 줄 수를 지정)을 불렀다. 문서에는 앞 단계 조정을 흉내 낸 구간별 자간(-3·-2·+1)과 굵게를 넣었다.

'바뀐 글자'는 시도 전 저장본과 글자 모양 정의가 다른 글자 수, '줄 수'는 본문 전체 화면줄 수다.

| 시나리오 | 쪽 수(전→후) | 줄 수 수정 전 | 줄 수 수정 후 | 바뀐 글자 수정 전 → 후 |
|---|---|---|---|---|
| 실패(직접·진입) | 2→2 | 69→66 | 69→69 | 134 → 0 |
| 첫 당김 뒤 취소 | 2→2 | 69→68 | 69→69 | 46 → 0 |
| 첫 당김 뒤 예외 | 2→2 | 69→68 | 69→69 | 46 → 0 |
| 성공(39문단) | 2→1 | 42→39 | 42→39 | 134 → 134 |
| 맞춤 불필요(9문단) | 1→1 | 14→14 | 14→14 | 0 → 0 |

- 성공·맞춤 불필요 문서의 저장본은 수정 전·후 `section0.xml`·`header.xml`이 **바이트 동일**하다.
- 실패 계열의 수정 후 저장본은 `header.xml`이 시도 전과 바이트 동일하다.
- 실패 계열의 `section0.xml`은 바이트 동일하지 **않다**. 글자 모양 번호가 같은 인접 구간이 나뉜 채 남는다. 그 구간을 합치고 줄 배치 캐시(`linesegarray`)를 빼면 시도 전과 같다.
- 첫 시도의 합성 문서는 한글 줄 나눔이 글자 단위여서 당김이 한 번도 성공하지 않았다(바뀐 글자 0). 어절 단위(`BreakNonLatinWord=0`, 프로브로 확인)로 다시 만든 결과가 위 표다.
- 복원 실패는 실제 한/글에서 만들지 않았고 가짜 hwp 시험으로만 확인했다.

## 남은 문제

- [판단 필요] **장평**: '장평 줄이기'(기본 꺼짐)를 켠 경우 당김이 줄인 장평은 1쪽 맞춤이 실패해도 남는다. 이번 지시는 자간만이라 두었다.

- 원복 뒤에도 같은 글자 모양의 구간 분리가 저장본에 남는다(화면 모양 같음).

- `font_widths.py` 주석과 `format_elements.py`의 어절/글자 표기가 서로 반대로 읽힌다. 이번 범위 밖이라 확인만 필요로 남긴다.
