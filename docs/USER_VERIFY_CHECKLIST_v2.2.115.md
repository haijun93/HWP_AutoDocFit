# v2.2.115 사용자 확인 목록

v2.2.90~v2.2.115에서 바뀐 것 가운데, 실제 PC에서 아직 확인하지 못한 것을 모았습니다.

- **1단 (7개, 약 30분)**: 문서 결과가 달라질 수 있는 것. 이것만 해도 됩니다.
- **2단 (7개)**: 파일이나 설치 상태가 손상될 수 있는 것.
- **3단 (13개)**: 그 밖. 쓰는 기능만 확인하세요.

## 시작하기 전에

1. **[설정]**에서 `현재 버전 v2.2.115`인지 확인합니다. 더 낮은 버전이면 아래 결과는 이번 확인으로 치지 않습니다.
2. 반드시 **시험용 폴더에 복사한 파일**로만 합니다. 원본과 중요한 사진·문서는 쓰지 않습니다.
3. 결과 칸에 `정상` / `이상` / `해당 없음` / `못 함`을 적습니다. 이상하면 화면을 캡처하고, 어떤 파일에서 무엇을 했는지 한 줄 적어 주세요.

> 단추·메뉴 이름은 프로그램 소스에서 확인한 것입니다. **(이름 미확인)** 표시는 확인하지 못한 것입니다. 실제 화면은 이 문서를 만들면서 실행해 보지 않았습니다.

## 1단. 문서 결과가 달라질 수 있는 것 (약 30분)

**준비할 시험 문서 (복사본 `.hwpx`)**
- **가**: 2쪽으로 살짝(1~4줄) 넘치는 1쪽짜리 보고서
- **나**: 칸이 하나인 표(개요 상자 등)가 있는 보고서
- **다**: `Ctrl+Enter`로 쪽을 나눈 3쪽 이상 보고서

**공통 순서**: **[문서편집]** → **[문서 추가]** → **[작업 방식 선택]** → **[한 번에 적용]**(**자간 조정 포함** 켬, **표 제외** 끔) → **[정리 시작]** → 끝나면 **[결과 확인]**.
가·나·다를 한꺼번에 넣으면 시간이 줄어듭니다. 처리 시간은 문서에 따라 다르며, 긴 문서는 30분을 넘길 수 있으니 짧은 문서를 쓰세요.

| 번호 | 어디에서 무엇을 하고 | 정상이면 보여야 하는 것 | 결과 |
| :-: | :--- | :--- | :-: |
| 1-1 | **한 칸 표** — 나를 처리하고 **[결과 파일 열기]**. 원본과 나란히 놓고 한 칸 표를 봅니다. | 표 안 글이 원본과 같고, 글자가 겹칠 만큼 좁아진 줄이 없습니다. 표가 몇 줄 길어질 수는 있습니다(의도한 변화). 길어진 탓에 쪽이 늘었거나 보기 나쁘면 `이상`. | |
| 1-2 | **줄 간격** — 처리한 결과에서 본문 몇 곳과 쪽 끝 문단의 문단 모양(`Alt+T`)을 봅니다. | 줄 간격이 **[설정]**의 **최소 줄 간격 (%)**~**최대 줄 간격 (%)**(처음 값 140~200%) 범위를 벗어나지 않고(원래 범위 밖이던 문단은 제외), 한 보고서 안에서 눈에 띄게 들쭉날쭉하지 않습니다. | |
| 1-3 | **1쪽 맞춤** — 가를 처리합니다. | 1쪽에 담기거나, 담지 못하고 2쪽으로 남습니다. 2쪽으로 남았을 때 마지막에 글자 간격이 유난히 좁아진 채 남은 문단이 없습니다. | |
| 1-4 | **쪽 나눔** — 다를 처리합니다. | `Ctrl+Enter`로 나눈 자리의 제목이 여전히 새 쪽에서 시작합니다. 앞쪽이 넘쳐 거의 빈 쪽이 생기지 않습니다. | |
| 1-5 | **덮어쓰기 방지** — 첫 결과 파일에 알아볼 글자를 한 줄 넣어 저장하고 닫습니다. **[새 작업 시작]** 후 같은 원본을 한 번 더 처리합니다. | 새 결과가 이름 뒤에 ` (2)`가 붙어 따로 생기고, 처음 결과에 넣은 글자와 원본은 그대로입니다. | |
| 1-6 | **실패 수** — 정상 문서 1개와, 내용을 아무 글자나 적은 가짜 파일 1개(`.txt`를 `.hwpx`로 이름만 바꾼 것)를 함께 넣고 처리합니다. | 가짜 파일이 **실패한 문서**에 나오고 실패 수에 들어갑니다. 정상 문서는 이어서 처리됩니다. "모두 성공"처럼 보이지 않습니다. 가짜 파일을 넣을 수 없거나 그대로 열려 성공하면 `해당 없음`. | |
| 1-7 | **결과 목록** — 1단 처리 뒤 **[결과 확인]**의 **작업 메시지와 검수 결과**를 읽습니다. | `성공 N개 / 실패 N개`(또는 `성공 N개 · 실패 N개`)가 실제와 맞습니다. 저장은 됐지만 확인이 필요한 파일은 `검수 실패(저장됨)`·`무결성 확인 필요(저장됨)`로 따로 보입니다. 이 표시가 나왔다면 파일 이름을 적어 주세요. | |

**1단에서 알아 둘 한계** (`이상`이 아니라 이미 알고 있는 것)
- **장평 줄이기**(기본 꺼짐)나 조정한 글자 색 표시를 켜면, 1쪽 맞춤이 실패해도 줄인 장평·글자 색이 남습니다.
- `.hwp`로 연 문서 등에서는 `Ctrl+Enter` 쪽 나눔을 찾지 못할 수 있습니다. 구역 나눔 경계는 보지 않습니다.
- 쪽 나눔을 지키는 대신 일부 묶음이 쪽에 걸치거나, 같은 항목이 검수에 여러 번 적힐 수 있습니다.
- **폭 표 내어쓰기**(설정, 기본 꺼짐)를 전에 켜 둔 적이 있으면 켜진 채일 수 있습니다. 결과가 이상하면 이 설정이 켜져 있는지 함께 적어 주세요.

## 2단. 파일·설치가 손상될 수 있는 것

2-1~2-4는 **버려도 되는 복사본**만 든 시험 폴더에서 합니다. 2-5~2-7은 설치 상태가 바뀌므로, 할 수 있을 때만 하세요.

| 번호 | 어디에서 무엇을 하고 | 정상이면 보여야 하는 것 | 결과 |
| :-: | :--- | :--- | :-: |
| 2-1 | **복사·이동** — **[문서뷰]**에서 `Ctrl`·`Shift`+클릭으로 시험 파일 몇 개를 고르고 **폴더로 복사**, 이어서 **폴더 이동**(오른쪽 메뉴에서는 **이동**). 같은 이름이 이미 있는 폴더도 골라 봅니다. | 고른 파일만 옮겨집니다. 같은 이름은 덮어쓰지 않고 ` (2)`가 붙습니다. 다른 드라이브로 옮겨도 파일이 빠지지 않고 열립니다. | |
| 2-2 | **삭제** — **[사진뷰]**에서 시험 사진 2장을 골라 **삭제**(`Delete`). | **휴지통으로 보내기** 확인창이 뜨고, 확인하면 Windows 휴지통에 들어가 되살릴 수 있습니다. 휴지통 없이 바로 지워지면 `이상`. 되살려도 그 사진의 태그·즐겨찾기는 돌아오지 않습니다(알려진 동작). | |
| 2-3 | **이름 변경·되돌리기** — **[파일명 일괄변경]** → **파일 추가**로 시험 파일을 넣고 글자를 덧붙인 뒤 **이름 바꾸기 (Ctrl+S)** → **되돌리기**. | 미리보기와 같은 이름으로 바뀌고, 되돌리기로 전부 원래 이름이 됩니다. 확장자와 내용은 그대로입니다. | |
| 2-4 | **작업 중 닫기** — 시험 문서를 처리하는 도중에 앱 창을 닫아 봅니다. | **작업 중단하고 종료** / **계속 진행**을 묻습니다. **계속 진행**을 고르면 작업이 이어지고, 중단해도 원본은 그대로입니다. | |
| 2-5 | **업데이트 설치** — 새 버전을 설치할 일이 생기면, 먼저 앱·몽땅검색·퀵가상폴더를 트레이까지 모두 닫고 설치합니다. | 설치가 끝까지 됩니다. "설치가 완료되지 않았습니다"나 "설치 파일 일부가 빠져 있습니다"가 뜨지 않습니다. 앱이 열리고 설정·업무자료함 내용이 그대로입니다. | |
| 2-6 | **색인 서비스 재시작** — 설치 중 서비스를 다시 시작할지 묻거나, **[문서뷰]**·**[사진뷰]**에 노란 안내와 **서비스 재시작** 단추가 보일 때 누릅니다(**재시작** 확인 → 관리자 승인). 안 보이면 `해당 없음`. | "색인 서비스가 다시 시작되었습니다."가 나오고, 잠시 뒤 안내가 사라지며 검색이 됩니다. 취소하거나 승인을 거절해도 앱은 계속 쓸 수 있습니다. | |
| 2-7 | **탐색기 우클릭 변환** — **[설정]**의 **탐색기 우클릭 메뉴**를 켜고, 시험 파일 3~5개를 골라 우클릭 → (Windows 11은 **더 많은 옵션 표시**) → **몽땅파일변환**. 끝나면 설정을 끕니다. | 창이 하나만 뜨고 파일이 빠짐없이 들어옵니다. 원본은 그대로입니다. 설정을 끄면 메뉴가 사라집니다. | |

## 3단. 그 밖

| 번호 | 어디에서 무엇을 하고 | 정상이면 보여야 하는 것 | 결과 |
| :-: | :--- | :--- | :-: |
| 3-1 | **아웃라이너 한글 입력** — **[아웃라이너]**에서 한글을 조합하는 중에 `Enter`, `Tab`을 누릅니다. 빠르게 연달아 입력도 해 봅니다. | 마지막 글자가 지워지거나 빠지지 않고, 새 줄·들여쓰기가 한 번만 됩니다. 빠른 입력에서 글자가 빠지면 알려진 문제이니 얼마나 자주인지 적어 주세요. | |
| 3-2 | **아웃라이너 키** — `Ctrl+Z`/`Ctrl+Y`, `Alt+Shift+↑/↓`, `Alt+↑/↓`, `Ctrl+Enter`, 여러 줄 붙여넣기. | 차례로 되돌리기/다시 실행, 블록 이동, 블록 선택, TODO 표시 바꾸기, 줄마다 블록 생성. | |
| 3-3 | **아웃라이너 페이지·참조** — `[[`, `((`를 입력해 고르고, 시험 페이지 이름을 바꿉니다. | 후보 목록이 뜨고, 이름을 바꾸면 다른 페이지의 링크도 함께 바뀝니다. | |
| 3-4 | **사진뷰·문서뷰 목록** — **[사진뷰]**·**[문서뷰]**를 열고, 닫았다 다시 엽니다. | 두 번째에는 저장해 둔 목록이 곧 보이고 새 파일만 더해집니다. "검색 중 99%"에서 멈추거나 "0개"로만 나오지 않습니다. 기존 태그·즐겨찾기가 남아 있습니다. 사진이 아주 많으면 첫 촬영 정보 정리는 수십 분 걸릴 수 있습니다. | |
| 3-5 | **파일 열기와 제외 폴더** — 두 화면에서 파일을 더블클릭합니다. **[사진뷰]**의 제외 폴더(이름 미확인)와 썸네일 크기를 바꾼 뒤 앱을 다시 켭니다. | 연결 프로그램으로 파일이 열립니다. 바꾼 값이 유지되고 제외한 폴더의 사진은 안 보입니다. | |
| 3-6 | **몽땅클립보드 켜기** — 꺼져 있을 때 **몽땅클립보드 켜기**를 누릅니다. `Ctrl+Shift+V`를 어두운 모드에서도 열어 봅니다. | **켜는 중…** 뒤에 켜지고 창이 닫힙니다(최대 약 60초). 어두운 모드에서 글자가 잘 보입니다. 오래 걸리면 걸린 시간을 적어 주세요. | |
| 3-7 | **퀵몽땅검색** — `Ctrl+Alt+Space`. 한글로 파일 이름을 검색하고, `;`로 두 낱말을 나눠 검색합니다. 화면 배율 125~150%에서도 봅니다. | 있는 파일이 나옵니다. 두 낱말을 모두 만족하는 것만 나옵니다. 글자·칩이 겹치지 않습니다. 있는 파일이 0건이면 `이상`. | |
| 3-8 | **하단 Dock** — **[설정]**의 **메뉴 표시 방식**을 **하단 Dock**으로 바꿉니다. 다른 모니터·최대화 창에서도 봅니다. 확인 뒤 **사이드바**로 돌립니다. | Dock이 보이고 모서리에 검은 사각형이 없습니다. 아이콘마다 맞는 화면이 열립니다(업무자료함 아이콘은 업무자료함). | |
| 3-9 | **PDF 편집** — **[PDF 편집]**에 시험 PDF를 끌어다 놓고, 쪽 회전·순서 변경 후 저장합니다. | 끌어다 놓은 파일이 그대로 들어오고(다른 선택창이 뜨지 않음), 한글이 네모로 깨지지 않으며, 저장 결과가 화면과 같습니다. | |
| 3-10 | **PDF 압축** — **[파일변환]**의 PDF 압축에서 작은 목표 크기를 주고 **목표 미달 때 이미지 PDF**를 고릅니다. 권한이 걸린 PDF가 있으면 사본으로 함께 해 봅니다. | 목표에 맞춰 줄고, 그림으로 바뀐 경우 **이미지 PDF: 글자 선택·검색 불가**가 보입니다. | |
| 3-11 | **새 창 방식(선택)** — 평소 새 창을 쓰는 화면만, **새 창(Win32)으로 열기**로 열어 한글 입력·파일 선택·오른쪽 메뉴를 써 봅니다. 안 쓰면 `해당 없음`. | 창이 열리고 "프로그램을 찾을 수 없습니다"가 뜨지 않습니다. 입력과 파일 작업이 앱 안 화면처럼 됩니다. | |
| 3-12 | **퀵가상폴더** — 창을 열어(여는 방법 이름 미확인) 좁게 줄이고, 큰 아이콘 보기와 목록 보기를 바꿔 봅니다. | 안내 문구와 긴 파일 이름이 잘리지 않고, `[파일]`·`[링크]`·`[폴더]`가 한글로 보입니다. | |
| 3-13 | **화면 전환** — 왼쪽 메뉴의 화면을 차례로 눌러 봅니다. | "앱 연결을 기다리고 있습니다" 경고가 뜨지 않습니다. | |
