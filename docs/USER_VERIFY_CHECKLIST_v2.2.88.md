# v2.2.88 사용자 확인 체크리스트

이 문서는 **HWP AutoDocFit v2.2.88** 업데이트 후, 개발 환경(시험 및 화면 캡처)에서 직접 확인하지 못한 실제 PC 동작과 화면을 공공기관 실무 담당자분께서 직접 점검하실 수 있도록 안내하는 점검표입니다.

---

## 1. 사전 준비 (3줄)

1. 프로그램 실행 후 창 맨 위 제목 줄에 **'v2.2.88'**이 정상적으로 표시되는지 확인합니다.
2. 새 창 및 신규 기능을 확인하려면 **[설정]**(톱니바퀴 아이콘) 화면에서 해당 기능(설정 창 방식, 아웃라이너 방식, 탐색기 우클릭 메뉴, 메뉴 표시 방식 등)을 켜거나 변경해야 합니다.
3. 문서 작업 중인 실제 원본 파일 대신 **시험용 복사본 파일**을 사용하여 단계별로 점검을 진행해 주시기 바랍니다.

---

## 3. 색인 서비스 안내 (선택 항목)

전체 드라이브의 방대한 파일명을 1초 안에 초고속으로 검색하려면 관리자 권한으로 동작하는 **색인 서비스(`HwpAutoDocFit.Index`)**가 켜져 있어야 합니다. (근거 문서: `docs/INDEX_SERVICE_STATUS_2026-11-20.md`)

1. **서비스가 이미 켜져 있는지 확인하는 방법**:
   - 키보드의 `Ctrl + Shift + Esc`를 눌러 **[작업 관리자]**를 엽니다.
   - 왼쪽 메뉴에서 **[서비스]** 탭을 선택한 후, 이름 목록에서 `HwpAutoDocFit.Index` 항목을 찾습니다.
   - 상태가 **'실행 중'**으로 되어 있다면 이미 정상 작동하고 있는 상태입니다.
2. **서비스가 켜져 있지 않은 경우**:
   - 일반 사용자 권한으로는 전체 드라이브 MFT 색인 서비스를 시작할 수 없으며, 윈도우 관리자(UAC) 승인이 필요합니다.
   - 앱 설정 화면에서 서비스 설치 버튼을 찾기 어렵거나 `(화면 문구 미확인)`, 서비스를 켜는 과정에서 파이프 충돌이나 권한 오류가 발생할 경우 무리하게 설정을 진행하지 마시고 **개발자에게 원격 지원 또는 도움을 요청**해 주시기 바랍니다.
