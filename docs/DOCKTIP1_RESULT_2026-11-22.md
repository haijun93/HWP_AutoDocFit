# DOCKTIP1 결과 (2026-11-22)

## 변경 내용

- 마우스를 올린 이름을 `맑은 고딕` 9 DIP, ClearType으로 그리며 기존 400ms 표시 지연과 `tooltip_visible` 판정 조건을 유지했다.
- 글자 폭에 맞춰 작은 둥근 배경·테두리를 만들고 독 알약 상단에 표시한다. 아이콘 줄은 아래로 옮기고 독 높이를 56에서 76 DIP로 늘려 두 영역을 분리했다. 이름 너비와 anchor 위치는 DPI 반영 순수 함수에서 계산하며 가용 폭 경계에서 좌우를 보정한다.
- 포인터가 독 밖으로 나가거나 클릭·독 숨김 상태가 되면 hover 표시 상태를 지운다.
- `--capture-dir` 전용 `--hover-tab N` 옵션을 추가했다. 실제 독 실행 경로에서는 사용되지 않는다.

- `cargo test --release --locked`: 성공. lib 15/15, native 바이너리 2/2, doctest 0. 모든 `test result` 성공.

- 캡처 위치: `E:/docfit-tmp/DOCKTIP1-captures` (저장소 외부 임시 자료).
