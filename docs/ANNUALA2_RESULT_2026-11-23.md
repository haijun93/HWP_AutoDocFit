# ANNUALA2 결과 — 주차별 문서 추이 SVG

## 변경

- `kfind/annual/src/output.rs`에 `weekly_documents_svg(input)`를 추가했습니다. `topic_by_iso_week`에서 연도가 다른 같은 ISO 주차를 합산해 1~53주차 막대를 그립니다.
- 최댓값 0에도 0 나눗셈이 없으며, 제목·접근성용 `<title>`/`<desc>`·축·눈금을 출력합니다. 주차 라벨은 4주 간격과 53주차로 간격을 뒀습니다. 막대의 SVG `<title>`에는 주차별 수치를 넣었습니다.
- `write_outputs`가 `주차별_문서수.svg`를 추가로 기록합니다. 기존 출력 파일명과 형식은 그대로 유지했습니다.
- 테스트를 추가했습니다: 빈 입력/태그 균형, 정상 합산과 스케일, 53주 경계, 최댓값 0, 파일 출력.

## 시험

`CARGO_TARGET_DIR="$HOME/cargo-target-ANNUALA2" cargo test --manifest-path kfind/annual/Cargo.toml` 실행은 Cargo가 `errno v0.3.15` 다운로드를 시도한 뒤 네트워크 호스트를 찾지 못해 중단했습니다. 재시도 방지를 위해 취소하고 `--offline`로 다시 실행했으나, 같은 패키지가 로컬 캐시에 없어 테스트 시작 전에 종료됐습니다.

- `cargo test`의 `test result` 출력 줄: **없음** (시험 바이너리 실행 전 의존성 확보 단계에서 중단).
- `git diff --check`: 통과.
- Cargo 전체 단위 시험: 실행되지 못함.
