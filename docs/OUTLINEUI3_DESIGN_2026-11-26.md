# OUTLINEUI3 설계 — 입력 후보·빠른 검색·명령 팔레트

- 범위: `outliner_win` Rust+Win32만 확장. 새 외부 의존성·XML 파서 없음. 설치본·서비스·자동 실행·사용자 설정·Flutter·기본 실행 선택은 변경하지 않는다.
- 선행 조건: OUTLINEUI2 커밋 `e4a5e2d8` 및 결과 문서의 core 130·win 159·Python 33 통과 기록 확인 후 지시한 병합 완료. 병합 기준 시험을 다시 실행한다.
- 결과: `docs/OUTLINEUI3_RESULT_2026-11-26.md`, `TODO.md`, `reports/PM-HANDOVER.md`. 로컬 커밋만, 푸시 없음.

| 상태 | 진입·전이·금지 |
|---|---|
| 편집 후보 닫힘 / 페이지 / 블록 / 태그 / 슬래시 | 캐럿의 가장 가까운 유효 트리거로 전이. 선택 영역·코드·일반 URL에는 열지 않는다. ↑↓·Enter/Tab·Esc·마우스 선택을 공유한다. Esc 이후 같은 트리거는 억제한다. |
| IME 조합·후보창 | 조합 중 기존 후보는 고정하고 치환 금지. 첫 트리거는 확정된 접두를 표시 전용으로 읽어 후보 문맥을 만들며 문서에는 반영하지 않는다. IME 화살표·Esc를 소유한다. Enter/Tab은 확정만 하고 다음 키에서 선택한다. 비동기 확정 중 팝업 클릭으로 치환하지 않는다. |
| 일반 검색 / 빠른 검색 / 명령 팔레트 | 기존 검색 호환을 유지하고 Ctrl+K는 빠른 검색, Ctrl+Shift+P는 팔레트로 진입. 편집 글 확정이 실패하면 진입하지 않는다. Esc로 닫고 본문으로 복귀. 새 페이지는 명시적으로 생성 행을 선택한 경우에만 생성한다. |
| 후보 선택·실행 | 선택 시 문맥을 다시 검증한다. 오래된 문맥·선택 범위·IME 조합이면 원문 불변. 문서 확정과 실행 취소는 기존 Editor 경로를 사용한다. |

- 슬래시 지원: TODO·DONE, 제목 h1~h3, 오늘 날짜, 페이지 참조, 블록 참조. 한국어 설명·영문 명령으로 검색한다. 지원하지 않는 Logseq 명령을 표시하지 않는다.
- 페이지 완성은 최근·접두·포함 순. 태그는 저장 그래프의 태그와 페이지 이름 및 현재 메모리를 사용한다. 블록 후보는 본문과 식별자를 함께 표시한다. 타 페이지 참조는 영구 `id::`가 있는 블록만 후보로 제공한다. 로컬 숫자 ID를 타 페이지 식별자로 사용하지 않는다.
- 빠른 검색은 빈 질의에서 최근 페이지, 1글자부터 페이지 이름, 2글자부터 블록 본문을 제공한다. 유효하고 아직 없는 이름은 마지막 생성 행에 둔다. 읽기 전용 후보 갱신은 파일을 만들지 않는다.
- 팔레트는 현재 Rust 창에서 실제 실행 가능한 저장·실행 취소·다시 실행·패널 전환·오늘·새 페이지·이름 변경·TODO·접기·펼치기만 제공한다. 삭제·설치·서비스 명령 없음.
- Logseq 근거: 파일 그래프 판 0.10.9의 [단축키 정의](https://github.com/logseq/logseq/blob/0.10.9/src/main/frontend/modules/shortcut/config.cljs#L145-L157), [빠른 검색·팔레트](https://github.com/logseq/logseq/blob/0.10.9/src/main/frontend/modules/shortcut/config.cljs#L320-L325), [슬래시 명령](https://github.com/logseq/logseq/blob/0.10.9/src/main/frontend/commands.cljs). 공개 동작만 참고하며 코드는 복사하지 않는다. Tab 완성은 이 창의 기존 호환 단축키다.
- 검증: 변경 크레이트 cargo test 전체, 관련 Python 시험, 합성 자료의 실제 Win32 EDIT/메시지·한글 조합 경계·3테마/2배율 캡처. 실제 한국어 IME 물리 입력과 메시지 기반 시험은 구분하여 보고한다. 속도 목표나 실측 개선은 측정 없이 주장하지 않는다.
