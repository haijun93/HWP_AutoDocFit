# 한/글 COM 호출 횟수와 절감 후보 (2026-11-18)

## 조사 범위와 계수 기준

읽기 전용으로 `hwp-auto-docfit.py`, `docfit_engine/`, 계측기 및 제공된 참고 문서를 확인했다. 프로그램·한/글 COM·시험은 실행하지 않았다. 이 문서의 줄 번호는 2026-11-18 조사 시점의 작업 트리 기준이다.

`docfit_core/com_perf.py`의 `ComProxy`는 COM 메서드 호출뿐 아니라 속성 읽기·쓰기와 인덱스 접근도 각각 기록한다. 따라서 SPD2 보고서의 “COM 기록” 숫자는 함수 호출 수와 동일하지 않다. 현재 저장소에서 `.comperf.json` 또는 baseline 결과 파일은 찾지 못했다. 아래 상위 10곳은 실행 계측 순위가 아니라, 소스의 반복 구조와 한 반복에서 확인되는 COM 호출 밀도로 추린 정적 우선순위다. 실제 실행 횟수 순위 및 문서별 횟수는 **확인 못 함**.

## 묶거나 줄이는 후보와 결과 위험

1. **줄 경계 읽기·글자 경계 읽기의 인자 정확한 기억 확대**: SPD2는 줄범위와 경계 검사 묶음을 `reuse` 모드에서 재사용해 같은 시연 문서 기준 전체 COM 기록 144,274→128,702, 본문 자간 1차 67,086→55,752를 기록했다. 다만 이는 1회씩의 관찰값이고 opt-in 전체 효과이며 시간 보장이 아니다. 편집 전/후 상태, 커서 위치와 범위 인자를 엄밀히 키로 유지해야 한다. 조판이 바뀐 뒤 낡은 경계를 쓰면 다른 어절 경계 판정 및 자간 결과가 생길 수 있다. 기본 활성화는 별도 동일성 검증 후 판단한다.
2. **Run/SetPos/GetPos/InitScan 반복 묶기**: `단어모드_줄범위`, `단어모드_한글자`, `_문단세트_줄순회`에서 커서 이동·위치 확인·텍스트 스캔을 한 helper가 한 번에 처리하고 호출자가 이미 읽은 위치/텍스트를 넘기는 방식의 후보가 있다. 위치 계약을 바꾸거나 `Cancel`/복원 이동을 생략하면 현재 선택·커서가 달라져 다음 편집 대상이 달라질 수 있다. `GetText`는 고정폭·묶음 공백을 생략할 수 있다는 HANDOVER 주의사항도 있어, XML 본문 텍스트로 무조건 대체하면 위치 대응이 달라질 위험이 있다.
3. **반복 서식 적용을 `batch_format.py`/HWPX XML 일괄 편집으로 이동**: 반복 `CreateAction`·`Execute`를 줄일 여지가 있다. XML 적용 가능 범위는 단순·유일한 본문 등 제한이 있고, COM 조판 기반 줄바꿈·페이지 계산과 서식 상속이 필요한 내어쓰기·쪽 맞춤을 XML로 치환하면 결과가 달라질 수 있다. TODO의 “한/글은 내어쓰기·쪽 맞춤만 하는 2단계 구조”는 검토 항목이지 현재 구현 사실이 아니다. 사용자 문서 원본 대신 사본으로 결과 구조·문단/서식 XML 차이를 비교해야 한다.

그 밖의 일괄 적용은 `CreateAction`/파라미터 설정 수를 줄일 수 있지만, 한/글의 선택 영역별 상속·혼합 서식 처리 차이가 확인되지 않았다. 구체적으로 안전한 범위는 **확인 못 함**.

## 후속 구현 제안 (3개 이내, 순서)

1. **기준 계측과 핫 루프 분해**: 동일한 시연 문서 사본·옵션으로 `scripts/perf_baseline_pc.py` 및 `DOCFIT_COM_PERF=1` 결과를 수집하고, 단계별·호출별·호출자별 숫자로 상위 10을 확정한다. 실행은 Windows 한/글 PC에서만 하며 `.com-test.lock`을 잡고 한 번에 한 COM 시험만 수행한다. 정적 우선순위와 실제 순위가 다르면 보고서를 갱신한다.
2. **반복 읽기 묶음의 좁은 최적화**: `Run`/`SetPos`/`GetPos`/스캔 경로 중 하나(우선 `단어모드_줄범위` 또는 `_문단세트_줄순회`)만 기능 브랜치에서 바꾸고, 커서 복원·취소·선택 계약을 시험한다. 같은 사본의 변경 전후 HWPX 구조/본문/서식 비교를 하고, COM 기록이 줄면서 차이가 0인지 확인한다. SPD2와 같이 기억 기능은 opt-in 검증부터 진행한다.
3. **서식 적용의 XML/COM 경계 검토**: `batch_format.py` 적용 후보를 정하고 내어쓰기·쪽 맞춤은 별도 대상으로 둔다. XML 적용 전후 차이와 실제 한/글 렌더/조판을 사본으로 비교하고 전체 Python 시험을 실행한다. 시험은 `python -m unittest discover -s tests`; 한/글 검증은 잠금 파일을 확보한 Windows PC에서만 별도 실행한다. 동등성 실패 시 범위를 축소하거나 COM 경로를 유지한다.

이 조사 자체에서는 코드나 시험을 실행·수정하지 않았고 COM 호출 횟수 실측도 하지 않았다.
