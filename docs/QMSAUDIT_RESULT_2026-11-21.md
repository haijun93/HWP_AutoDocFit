# QMSAUDIT 결과 — 퀵몽땅검색(ktm) 화면 캡처 전수 점검 (2026-11-21)

## 1. 방법
- `ktm.exe --capture-dir <폴더> [--theme light|dark] [--dpi 96|144] [--size 가로x세로] [--scenario <이름>|all]`
  로 창 없이 실제 `draw` 경로를 메모리 DC에 그려 PNG를 만들었다(서비스·Everything·트레이를 건드리지 않음).
- 캡처 모드 확장(이번 카드): 장면 4개 추가 — `21_mixed_names`(한글·영문·숫자 혼합·긴 이름),
  `22_date_today`, `23_date_year`, `24_error_incomplete`, 그리고 `--size`(최소 창 크기 520x300 점검용).
  `15_sidebar` 장면은 실제 앱처럼 사이드바 폭만큼 창을 넓힌다.
- 조합: 라이트·다크 × 96·144 dpi(150%에 가까운 배율) × 장면 24개 + 최소 크기(96dpi 라이트).
  장면 전부를 직접 열어 본 것은 아니고, 장면 종류별 대표를 열어 확인했다(§5 미확인 참고).
- 상호작용 점검(히트 테스트·칩 클릭·옵션 팝업) 14건 모두 PASS(전·후 동일).

## 3. 수정 내역(전 → 후)
캡처 산출물은 저장소에 넣지 않았다(PC 전용 경로 금지). 같은 명령으로 다시 만들 수 있다.

1. **오류 화면 겹침**(`ktm/src/window.rs` ⑥a·⑥b): ⑥a 제목을 '검색을 완료하지 못했습니다'로 통일하고,
   ⑥b에서는 `Phase::Error`를 제외했다. 전: 두 문구가 겹쳐 판독 불가 → 후: 제목 1줄 + 사유 줄바꿈 표시.
2. **모달 배경 어둡게**: `fill(r, 0x70000000)` 대신 `AlphaBlend`로 검정을 약 44% 합성. 전: 검정 면 → 후: 뒤 화면이 어둡게 비침(라이트·다크 모두 확인).
3. **사이드바 폭**: 창을 열 때(`Effect::Show`)와 사이드바 토글 때(`resize_for_sidebar`) 창 폭을
   `SIDEBAR_W`(220px)만큼 넓히고 닫으면 줄인다(작업 영역 초과 시 제한). 전: 700px 중 480px만 내용 → 후: 920px, 내용 700px 유지, 칩·단추 모두 보임.
4. **긴 이름 말줄임**: `highlighted()`가 한 줄을 넘는 이름 끝에 '…'을 그린다.
5. **캡처 자료**: `18_no_results`에서 폴더 개수 비움.

## 6. 사용자 실기 확인 항목(미확인)
- 실제 마우스로 사이드바 토글 시 창이 넓어지고 화면 가장자리·모니터 경계에서 어색하지 않은지(다중 모니터·작업 영역 경계).
- 실제 모니터 배율 100·125·150%·혼합 DPI 이동.
- 한글 IME 입력 중 '…' 말줄임·하이라이트 위치.
- 모달 열림 상태에서 입력칸이 숨겨지는 동작(캡처로는 확인 불가).
- 캡처는 메모리 DC 렌더라 실제 DWM 그림자·테두리와 완전히 같지 않다. 144dpi는 150%가 아니라 144(150%에 가까움)로 확인했다.
