## 2. 주간 진행 요약 (완료 · 진행 · 남은 일)

### 가. 11-22 현재 완료된 항목
1. **문서뷰·사진뷰 Win32 전용 새 창 및 셸 썸네일 고속 공급 (v2.2.89)**
   - 가볍고 빠른 Win32 격자 화면(`docview_win`, `photoview_win`, 공용 크레이트 `grid_core`) 1~2단계 구현 완료.
   - 탐색기(셸) 미리보기 썸네일을 4개 작업 스레드와 64MiB 캐시로 화면에 보이는 칸부터 초고속으로 공급(THUMBSHELL2).
   - 설정 `docview_ui: native`, `photoview_ui: native`로 선택적 활성화 가능.
2. **아웃라이너 Win32 전용 새 창 패리티 하네스 완료 (v2.2.89)**
   - Flutter 화면 대비 차이 0 검증 하네스(`parity.rs`) 및 새 블록·들여쓰기·페이지 이름 필터 격차 해소(OUTLINERWIN5).
3. **앱 설정 Win32 전용 창 보강 (v2.2.89)**
   - 목록 컨트롤 키 2개(`hidden_tabs`, `library_excluded_folders`) 대응 및 중복 실행 방지(SETTINGSWIN4, KCLIPSET4).
4. **실행 파일 크기 대폭 절감 (릴리스 프로필 정비, v2.2.89)**
   - LTO·strip 적용으로 `kfind`, `outliner`, `pdf-edit`, `qms_bench` 실행 파일 크기 15~80% 감소.
   - `klib` 미사용 검색 기능(stemmer/stopwords) 제거로 추가 경량화.
5. **검색 서비스 오류 및 패닉 파일 로그 신설 (v2.2.89)**
   - `kfind` 서비스 오류를 `%LOCALAPPDATA%\HwpAutoDocFit\logs\kfind-service.log`(256KiB 회전)에 자동 기록.
6. **탐색기 우클릭 메뉴 프로세스 간 파이프 전달 (v2.2.89)**
   - 실행 중인 메인 앱에 파일 경로를 직접 전달하는 파이프 배선 완료.
7. **파일변환 Win32 전용 창 1단계 구현 (v2.2.90)**
   - 변환 대상 형식 선택, 파일 목록, 변환 진행률 표시 및 취소 기능(`convert_win`, CONVWIN2~4) 구현 완료.
   - 설정 `conversion_ui: native` 지원.
8. **파일명 일괄변경 Win32 전용 창 1~2단계 구현 (v2.2.90)**
   - 파일 끌어놓기(드롭), 파일 열기 대화상자, 규칙 입력, 충돌 판정 미리보기(`rename_win`, RENAMEWIN2·4) 구현 완료.
   - 설정 `rename_ui: native` 지원.
9. **하단 Dock 자동 숨김 기능 (v2.2.90)**
   - 설정 `dock_auto_hide: true` 시 겹치는 창이 있으면 숨고, 화면 맨 아래 가장자리(2px) 마우스 호버 시 재등장하는 기능 보강(DOCK2).
10. **설치 및 제거 작업 기록 신설 (v2.2.90)**

## 3. 사용자 실기 확인 대기 목록 (협조 요청)

프로그램의 안정성을 높이고 공공기관 실무 환경에 완벽히 맞추기 위해, 발주자 담당자분께 아래 4가지 사항에 대한 확인과 지원을 부탁드립니다.

1. **신규 릴리스(v2.2.88 ~ v2.2.90) 실기 기능 확인 및 점검표 회신 (가장 시급)**
   - 전달드린 점검표(`docs/USER_VERIFY_CHECKLIST_v2.2.88.md`, `v2.2.89.md`)를 바탕으로, 실제 업무 PC에서 아래 기능들의 작동을 확인해 주시기 바랍니다:
     - **아웃라이너 새 창**: 한글 입력(IME) 시 글자 끊김·씹힘 없이 자연스럽게 작성되는지
     - **문서뷰·사진뷰 새 창**: 설정에서 `native` 선택 시 격자 목록과 썸네일이 빠르게 뜨는지
     - **파일변환·파일명변경 새 창**: 설정에서 `native` 선택 시 새 창이 뜨고 파일 드롭 및 미리보기가 정상 표시되는지
     - **하단 Dock 자동 숨김**: 설정에서 자동 숨김을 켰을 때 창 겹침 시 숨고 가장자리에 마우스를 대면 다시 나타나는지
     - **실행 파일 크기 및 첫 실행 속도**: 이전 버전 대비 가벼워진 체감 속도
2. **한/글 연동 오류(-2147417851) 재현용 문서 사본 제공**
   - 문서 일괄 변환 또는 서식 처리 중 오류가 발생했던 실제 HWP/HWPX 문서 사본이 필요합니다. (민감한 본문 내용은 마스킹/대체 가능)
3. **위계(목차) 검색 평가용 실문서 사본 및 질의 전달**
   - 일반 공문서 양식 표본과 "이런 내용이 몇 페이지에 있는지 찾고 싶다"는 검색 질의 예시를 보내주시면 지능형 검색 정확도를 크게 향상시킬 수 있습니다.
4. **전문 검색 성능 측정을 위한 시험용 PC 또는 VM 환경 협조**
   - Everything과의 속도 및 메모리 비교 측정을 위한 독립 시험 환경 협조를 요청드립니다.
