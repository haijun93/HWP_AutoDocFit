# 1.80.10 알파 문서 구조 분석 보강

- 장 띠: 로마자 번호와 제목을 가진 1행 3칸(A), 1칸(B), 2칸(예외)을 구분한다. 절 띠는 아라비아 숫자 및 지정 사설영역 글리프 U+F02B2를 구분한다. 세부 띠와 □/ㅇ/- 본문 계층을 별도 노드로 기록한다.
- 순수 글자 절 제목은 기호뿐 아니라 글꼴·크기·강조 및 뒤 본문과의 관계를 함께 분석한다. 사설영역 글리프는 폰트 의존으로 표시하며 모든 사설영역 문자를 숫자로 추정하지 않는다.
- 2행 2열 이상 표의 바로 앞 한 줄 괄호형 제목을 부속 서식으로 수집한다. 빈 문단이 끼면 직접 인접한 표 제목으로 확정하지 않는다.
- 개요표 문단은 양쪽 정렬(JUSTIFY)을 적용한다. 공유 paraPr를 복제하여 다른 표·문단의 정렬은 보존한다. 저장 프로필의 개요 샘플, 보고서 생성 및 기존 폭 조정 경로에 연결한다.
- 새 장·절·세부 띠 종류와 표 부속 제목은 분석·검토 정보다. 아직 복제 실행 경로가 연결되지 않은 종류는 MODE_SHOW로 표시하여 적용 완료 통계에 포함하지 않는다. 기존 midtitle 복제 경로는 유지한다.

## 재연 시험의 판정 기준

- kordoc 생성 원본은 보존 비교용 입력이다. 잘못된 탭·내어쓰기·자간까지 그대로 복제한 결과를 규범 합격으로 판정하지 않는다.
- 규범 기준은 항목기호 뒤 U+0020 한 개, 앞 공백은 ㅁ/□ 0개·ㅇ 1개·- 3개다. *와 **는 부모 항목에 따른 기존 규칙을 적용한다.
- 원본 보존율과 규범 준수율을 분리하고, 수정한 속성·미지원·실패·미실행 항목을 모두 분모와 보고서에 남긴다. 100% 재연은 목표이며 현재 달성 보고가 아니다.
- 기관별 kordoc 예시 전종 생성·학습·한/글 실측은 TODO.md에 미착수로 유지한다. Linux 단위 시험은 Windows 한/글 조판 결과를 보증하지 않는다.
