상태 기계:

- 관리·파일명: 대기 → 요청 중 → 대기/오류. 파일명 적용·되돌리기는 작업 중 → 취소 요청 → 종료. 요청 중 중복 실행 금지, 적용 중 편집 금지, 종료 후 실제 목록 다시 읽기.
- 변환: 대기 → 실행 → 완료/실패/취소. 중단은 작업 프로세스가 안전 지점에서 처리하고 결과를 반환한 뒤 종료한다. 결과 경로를 추정해 성공 처리하지 않는다.
- 편집 초안이 있는 관리 창은 닫기 전에 확인한다. 다른 화면에서 받은 파일은 목록에만 추가한다.

Python 작업은 별도 프로세스의 제한된 JSON 명령으로 호출한다. 창 전달은 RUSTSIDE2 수신함 규약을 사용한다. Python 부트스트랩은 Tk/WebView/상주 작업 이전에 분기한다. XML은 기존 defusedxml 서비스만 사용한다.
